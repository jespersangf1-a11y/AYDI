## 1. Einfuehrung und Uebersicht

### 1.1 Definition und Funktion

Rollreffanlagen (engl. headsail furling systems, furlers) sind mechanische Systeme, die das Aufrollen und Reffen von Vorsegeln (Fock, Genua, Code 0, Gennaker) um das Vorstag oder eine dedizierte Profilfolie ermoeglichen. Sie ersetzen das traditionelle Segelwechseln auf dem Vorschiff und gehoeren zu den wichtigsten Komfort- und Sicherheitsverbesserungen im modernen Fahrtensegeln.

Die grundlegende Funktion einer Rollreffanlage besteht aus vier Elementen:

1. **Segelbergen** — Das Vorsegel wird durch Drehen der Profilfolie/des Vorstags um sich selbst aufgerollt, ohne dass Personal aufs Vorschiff muss
2. **Reffen** — Teilweises Einrollen reduziert die wirksame Segelflaeche stufenlos, angepasst an die Windstaerke
3. **Segelsetzen** — Durch Dichtholen der Genua-Schot und gleichzeitiges Fieren der Furler-Leine wird das Segel kontrolliert entrollt
4. **Profilgebung** — Die Foilsektionen halten das Vorliek in einer definierten aerodynamischen Form

### 1.2 Historische Entwicklung

**Vor 1970 — Fruehe Formen:**
- 1907: Erstes Patent fuer eine Rollgenua durch Captain du Boulay (Grossbritannien)
- 1920er: Wykeham-Martin Furler fuer Cruiser — einfacher Drehwirbel am Kopf, Leine an Trommel am Fuss
- 1930–1960: Seltene Verbreitung, kaum zuverlaessig, galten als "Anfaenger-Ausstattung"
- Probleme: Wickelfalten, unkontrolliertes Aufrollen bei Wind, schlechte Segelform

**1970–1985 — Moderne Rollreffanlage entsteht:**
- 1975: Hood Yacht Systems (Ted Hood) fuehrt die erste zuverlaessige Profilfoil-Rollreffanlage ein (Sea Furl)
- 1978: Profurl (Frankreich) gruendet sich, fuehrt Aluminium-Profilfolien ein
- 1980: Furlex (Selden, Schweden) kommt auf den Markt — wird zum europaeischen Standard
- 1982: Facnor (Frankreich) startet Produktion
- 1983: Harken Unit One — erster vollstaendig integrierter Furler mit Dichtlippenlager
- Aluminium-Strangpressprofile ersetzen die ersten Edelstahl-Rohrkonstruktionen

**1985–2000 — Verbreitung und Professionalisierung:**
- Rollreffanlagen werden Standard auf Fahrtenyachten ab 30 Fuss
- Wettfahrt-Furler fuer Code 0 und Gennaker erscheinen
- Elektrische Antriebe fuer Megayachten (Reckmann, Deutschland)
- Top-Down-Furler fuer asymmetrische Spinnaker (Facnor FX+)
- Under-Deck-Furler fuer optisch saubere Decks

**2000–2015 — Spezialisierung und Innovation:**
- Karver (Frankreich) entwickelt den Captive-Reel-Furler fuer Offshore-Racing
- Continuous-Line-Furler ersetzen die Trommel-Furler im Regattasport
- Anti-Torsion-Seile ermoeglichen trommellose Anfliegersysteme
- Harken MKIV und Profurl NEX als neue Generationen
- Carbon-Profilfolien fuer Performance-Yachten

**2015–heute — Elektrifizierung und Leichtbau:**
- Reckmann hydraulische und elektrische Systeme fuer Superyachten bis 60m+
- Selden Furlex 50S als kompaktester Cruising-Furler
- Facnor FXe elektrische Serie
- Karver mit Anti-Torsion-Integralsystemen
- Code-0-Furler werden Standard im Offshore-Racing (IMOCA, Class40)
- Integration in Autopilot-Systeme und Performance-Software
- Zunehmende Nachfrage nach nachruestbaren Systemen fuer aeltere Yachten

### 1.3 Bedeutung im modernen Yachtdesign

Im Kontext des AYDI-Analysesystems sind Rollreffanlagen ein kritischer Designparameter, der folgende Module beeinflusst:

- **Ergonomie-Modul:** Rollreffsysteme eliminieren die Notwendigkeit, bei Segelwechseln aufs Vorschiff zu gehen — zentrale Sicherheits- und Komfortverbesserung
- **Compliance-Modul:** CE-Kategorie beeinflusst die Anforderungen an Reffmoeglichkeiten, Sicherungssysteme und Fluchtweg-Freiheit auf dem Vorschiff
- **Kosten-Modul:** Rollreffanlagen repraesentieren typisch 3–8% der Rigg-Gesamtkosten, signifikant mehr bei elektrischen Systemen
- **Produktions-Modul:** Integration in den Mastbau, Vorstag-Konfiguration, Decksplanung
- **Gewichts-Modul:** Trommel und Foilsektionen am Vorstag beeinflussen den Pitching-Moment (Stampfbewegung)
- **Material-Modul:** UV-Bestaendigkeit der Anlage und des UV-Schutzstreifens am Segel
- **Struktur-Modul:** Hohe Vorstag-Spannung, Drucklast am Masttopp, Torsionskraefte bei gewickeltem Segel

## 2. Grundlagen und Theorie

### 2.1 Funktionsprinzip der Rollreffanlage

Das Grundprinzip jeder Rollreffanlage beruht auf der axialen Drehung des Vorstags oder einer das Vorstag umschliessenden Profilfolie um die Laengsachse. Das Vorsegel, befestigt am Vorliek entlang des Vorstags, wird dabei um die Achse aufgewickelt.

**Mechanische Grundkomponenten:**

```
┌─────────────────────────────┐
│     MASTTOP / HALYARD       │
│   ┌───────────────────┐     │
│   │  Oberer Wirbel    │     │  Swivel (Drehpunkt oben)
│   │  (Top Swivel)     │     │  Nimmt Halyard-Zug auf
│   └────────┬──────────┘     │
│            │                │
│   ┌────────┴──────────┐     │
│   │  Profilfolie      │     │  Foil Sections (Sektionen)
│   │  (Foil Extrusion) │     │  Umschliesst das Vorstag
│   │  mit Segelnut     │     │  Bietet Luff Groove fuer Segel
│   │  ···              │     │  Mehrere Sektionen verbunden
│   │  ···              │     │
│   └────────┬──────────┘     │
│            │                │
│   ┌────────┴──────────┐     │
│   │  Untere Trommel   │     │  Drum (Furling Drum)
│   │  (Furling Drum)   │     │  Hier greift die Furler-Leine an
│   │  + Lager          │     │  Torsion-Bearing nimmt Drehlast auf
│   └────────┬──────────┘     │
│            │                │
│   ┌────────┴──────────┐     │
│   │  Unterer Toggle   │     │  Befestigung am Bug
│   │  (Stemhead Ftg)   │     │  oder Bugbeschlag
│   └───────────────────┘     │
└─────────────────────────────┘
```

**Funktionsablauf — Segel einrollen (Furling):**

1. Genua-Schoten werden gefiert (Wind entlastet das Segel)
2. Furler-Leine (Control Line) wird dichtgeholt — dreht die Trommel
3. Trommel-Drehung uebertraegt sich ueber Foilsektionen auf das gesamte Vorstag-System
4. Segel wickelt sich von unten nach oben um die Foilprofile
5. UV-Schutzstreifen liegt aussen auf dem aufgerollten Segel
6. Furler-Leine wird belegt — Segel bleibt aufgerollt

**Funktionsablauf — Segel ausrollen (Unfurling):**

1. Furler-Leine wird vom Beleger geloest und kontrolliert gefiert
2. Lee-seitige Genua-Schot wird dichtgeholt
3. Winddruck im Segel unterstuetzt das Ausrollen
4. Segel entfaltet sich vollstaendig
5. Furler-Leine wird belegt (mit Restspannung fuer sauberen Wickel)

### 2.2 Trommel-Mechanik (Furling Drum Mechanics)

Die Furling-Trommel ist das Herzsttueck der Anlage. Sie wandelt die lineare Zugkraft der Furler-Leine in eine Drehbewegung des Vorstag-Systems um.

**Trommeltypen:**

| Typ | Beschreibung | Einsatz |
|-----|-------------|---------|
| Offene Trommel | Freiliegende Trommel mit Leinenwicklung sichtbar | Kleinere Boote, Budget-Systeme |
| Geschlossene Trommel | Vollstaendig gekapselte Trommel | Standard Cruising, UV-geschuetzt |
| Continuous-Line-Trommel | Endlosleine ohne Wickeltrommel — Leine laeuft ueber Umlenkrolle | Racing, Kurzhand |
| Under-Deck-Trommel | Trommel unter Deck montiert | Superyachten, Clean-Deck |
| Captive-Reel | Selbsteinziehende Trommel mit Federspannung | Racing (Karver-System) |

**Mechanische Uebersetzung:**

Die Furler-Leine wickelt sich auf der Trommel (Durchmesser D_trommel) und dreht dabei die Foilsektion (Durchmesser D_foil). Das Uebersetzungsverhaeltnis bestimmt die benoetigte Leinenlaenge:

```
Uebersetzungsverhaeltnis (i) = D_trommel / D_foil

Benoetigte Leinenlaenge (L_leine):
  L_leine = n_umdrehungen × π × D_trommel_mittel

  Wobei:
  n_umdrehungen = Vorstag-Laenge / (π × D_foil)
  D_trommel_mittel = (D_trommel_aussen + D_trommel_innen) / 2
```

**Typische Werte:**

| Bootgroesse | D_foil (mm) | D_trommel (mm) | n_umdrehungen | Leinenlaenge (m) |
|------------|------------|---------------|---------------|-------------------|
| 25–30 ft | 18–22 | 80–100 | 12–15 | 3.0–4.7 |
| 30–36 ft | 22–28 | 100–130 | 10–14 | 3.1–5.7 |
| 36–42 ft | 28–35 | 130–170 | 9–13 | 3.7–6.9 |
| 42–50 ft | 35–45 | 170–220 | 8–12 | 4.3–8.3 |
| 50–60 ft | 45–55 | 220–280 | 7–11 | 4.8–9.7 |

**Lager-Technologie:**

| Lagertyp | Beschreibung | Vorteile | Nachteile |
|----------|-------------|----------|-----------|
| Nadellager | Zylindrische Waelzkoerper | Hohe Tragfaehigkeit, kompakt | Empfindlich gegen Schmutz |
| Kugellager (Edelstahl) | Standard-Kugellager 316L | Zuverlaessig, wartungsarm | Schwerer, teurer |
| Torlon-Gleitlager | Kunststoff-Gleitlager (PAI) | Salzwasserresistent, leicht | Hoehere Reibung, Verschleiss |
| Keramik-Hybrid-Lager | Si3N4-Kugeln, Stahlring | Korrosionsfrei, leicht | Sehr teuer |
| Dichtlippenlager | Gedichtete Kugellager | Wartungsarm, geschuetzt | Hoehere Anlaufreibung |

### 2.3 Profilfolie (Foil Extrusions)

Die Profilfolie ist das Aluminium-Strangpressprofil, das das Vorstag umschliesst und gleichzeitig die Segelfuehrungsnut (Luff Groove) bildet.

**Foilprofile — Querschnittsformen:**

```
Typ A — Runder Foil (Standard Cruising)
  ┌──────────┐
  │  ╭────╮  │
  │  │ ○  │──│── Segelnut (Luff Groove)
  │  │Stay│  │
  │  ╰────╯  │
  └──────────┘
  Durchmesser: 18–55mm je nach Groesse
  Beispiele: Selden Furlex, Profurl C-Serie

Typ B — Tropfenfoermiger Foil (Performance)
  ┌──────────┐
  │  ╭──╮    │
  │  │○ ╰──╮─│── Segelnut (Luff Groove)
  │  │Stay  │ │
  │  ╰──╮──╯ │
  │     ╰╯   │
  └──────────┘
  Chord-Laenge: 30–80mm
  Beispiele: Harken MKIV, Profurl NEX

Typ C — Twin-Groove-Foil (Segelwechsel unter Last)
  ┌────────────┐
  │    ╭────╮  │
  │ ──│ ○  │──│── Zwei Segelnuten (Dual Luff Groove)
  │    │Stay│  │
  │ ──│    │──│── Ermoeglicht Segelwechsel ohne Bergen
  │    ╰────╯  │
  └────────────┘
  Beispiele: Profurl C420/C480 Twin
```

**Foilsektionen-Verbindung:**

Die Profilfoile werden in Sektionen von typisch 2,0–2,5m Laenge geliefert und mit Verbindungsstuecken (Foil Connectors) zusammengesetzt.

| Verbindungstyp | Beschreibung | Vorteile | Nachteile |
|---------------|-------------|----------|-----------|
| Steckverbindung (Snap-Lock) | Sektionen rasten ineinander | Schnelle Montage, kein Werkzeug | Kann sich loesen, Spiel |
| Schraubverbindung | Sektionen verschraubt | Sicher, kein Spiel | Zeitaufwaendige Montage |
| Pressverbindung | Verbinder wird in Sektionen gepresst | Dauerhaft, kein Spiel | Nicht demontierbar |
| Klemm-Verbindung | Aussenhuelsse mit Klemmschraube | Einstellbar, nachruestbar | Kann sich lockern |

### 2.4 Vorliek-Befestigung: Luff Wire vs. Luff Tape vs. Integral Foil

Die Art, wie das Segel am Vorstag bzw. an der Profilfolie befestigt ist, hat fundamentalen Einfluss auf die Segelform, besonders beim Reffen.

**Luff Wire (Vorliekdraht):**
- Stahldraht (1×19 oder 7×19) ist im Vorliek des Segels eingenaeht
- Segel und Draht bilden eine Einheit — der Draht IST das Vorstag
- Trommel dreht den Luff Wire direkt
- Aeltere und einfachere Systeme
- Vorteile: Guenstig, einfach, leicht
- Nachteile: Schlechte Segelform beim Reffen (kein Profilfoil), Draht kann ermueden, kein Twin-Groove moeglich

**Luff Tape (Vorliekband):**
- Kevlar- oder Dacron-Band am Vorliek, das in die Profilfoil-Nut eingefuehrt wird
- Vorstag und Segel sind getrennte Elemente
- Standardbefestigung bei modernen Profilfoil-Systemen
- Vorteile: Segel wechselbar, gute Segelform durch Foil-Unterstuetzung, verschiedene Segel einsetzbar
- Nachteile: Luff Tape kann sich im Foil verklemmen, empfindlicher Einfaedelprozess

**Integral Foil (Integrales Foilsystem):**
- Segel hat ein speziell geformtes Vorliek, das selbst Teil des aerodynamischen Profils ist
- Kein separater Vorstag-Draht — das Foilsystem traegt die gesamte Last
- Typisch bei Code-0- und Gennaker-Furlern
- Vorteile: Beste Aerodynamik, leichteste Loesung, keine Vorstag-Reibung
- Nachteile: Teuer, segel- und furlerspezifisch, nicht nachruestbar auf konventionelle Systeme

**Vergleichstabelle:**

| Kriterium | Luff Wire | Luff Tape | Integral Foil |
|-----------|----------|-----------|---------------|
| Segelform voll | Gut | Sehr gut | Exzellent |
| Segelform gerefft | Maessig | Gut | Nicht vorgesehen (0 oder 100%) |
| Gewicht | Leicht | Mittel | Sehr leicht |
| Kosten | Niedrig (€200–600) | Mittel (€400–1.200) | Hoch (€800–3.000) |
| Segelwechsel | Aufwaendig (Segel=Vorstag) | Einfach | Einfach (aber spezifisch) |
| Nachruestbarkeit | Hoch | Mittel | Niedrig |
| Typischer Einsatz | Kleine Yachten, Budget | Standard Cruising/Racing | Code 0, Gennaker, Performance |

### 2.5 Drehmoment-Anforderungen (Torque Requirements)

Das zum Einrollen des Segels benoetigte Drehmoment haengt von mehreren Faktoren ab und bestimmt die Dimensionierung der gesamten Anlage.

**Faktoren fuer das Einroll-Drehmoment:**

1. **Segelflaeche** — Groessere Flaeche = mehr Drehmoment
2. **Windstaerke** — Hoeherer Winddruck = mehr Widerstand beim Rollen
3. **Wickeldurchmesser** — Je mehr Segel aufgerollt ist, desto groesser der Wickeldurchmesser und das benoetigte Drehmoment
4. **Reibung** — Lager, Foilverbindungen, Luff-Tape-Reibung
5. **Vorstag-Durchhang** — Durchhaengendes Vorstag erhoeht den Rollwiderstand
6. **Segel-Steifigkeit** — Laminatsegel rollen schwerer als Dacron

**Drehmoment-Abschaetzung (Faustformel):**

```
M_furling (Nm) ≈ Segelflaeche (m²) × Winddruck (N/m²) × Hebelarm (m)

Wobei:
  Winddruck = 0.5 × ρ × V² × Cd
    ρ = 1.225 kg/m³ (Luftdichte)
    V = Windgeschwindigkeit (m/s)
    Cd ≈ 1.2 (Widerstandsbeiwert aufrollendes Segel)

  Hebelarm ≈ D_wickel / 2 (nimmt mit Aufrollgrad zu)
```

**Typische Drehmoment-Werte (bei 20 kn Wind, Segel halb eingerollt):**

| Bootgroesse | Segelflaeche (m²) | Drehmoment Trommel (Nm) | Drehmoment oberer Wirbel (Nm) |
|------------|-------------------|------------------------|-------------------------------|
| 25–30 ft | 15–25 | 8–15 | 3–6 |
| 30–36 ft | 25–40 | 15–30 | 6–12 |
| 36–42 ft | 35–55 | 25–50 | 10–20 |
| 42–50 ft | 50–80 | 40–80 | 18–35 |
| 50–60 ft | 75–120 | 70–140 | 30–60 |
| 60–80 ft | 110–180 | 120–250 | 50–110 |

**Sicherheitsfaktor:** Alle Furler-Hersteller dimensionieren mit einem Sicherheitsfaktor von mindestens 2,5–3,0 ueber dem maximalen Betriebsdrehmoment.

### 2.6 UV-Schutzstreifen (UV Protection Strips)

Der UV-Schutzstreifen ist ein oft unterschaetztes, aber kritisches Element. Aufgerollte Segel sind permanent UV-Strahlung ausgesetzt, die das Segeltuch (besonders Dacron und Laminat) innerhalb weniger Saisons degradiert.

**Typen von UV-Schutz:**

| Typ | Beschreibung | Lebensdauer | Kosten |
|-----|-------------|-------------|--------|
| Aufgenaehter UV-Streifen (Sunbrella) | Acryl-Stoff am Achterliek und Unterliek aufgenaeht | 5–8 Jahre (Mittelmeer), 8–12 Jahre (Nordeuropa) | €150–400 |
| Aufgenaehter UV-Streifen (Dacron) | Dacron-Stoff, oft in Segelfarbe | 3–5 Jahre (Mittelmeer), 5–8 Jahre (Nordeuropa) | €100–250 |
| UV-Folie (selbstklebend) | Nachtraeglich aufklebbare UV-Folie | 2–3 Jahre | €50–150 |
| Segel-Persenning (Sail Cover) | Separate Schutzhuelle ueber aufgerolltem Segel | 8–15 Jahre | €200–600 |
| Keine UV-Behandlung | Oft bei Racing-Segeln (werden abgeschlagen) | — | €0 |

**UV-Streifen-Dimensionierung:**

Der UV-Streifen muss bei vollstaendig eingerolltem Segel die gesamte exponierte Flaeche abdecken:

```
Breite UV-Streifen = π × D_aufgerollt + Sicherheitszugabe (50mm)

D_aufgerollt = D_foil + 2 × n_lagen × Tuchdicke

Typische Werte:
  Tuchdicke Dacron: 0.3–0.5mm pro Lage
  Typisch 8–15 Lagen bei voller Aufrollung
  D_aufgerollt = 30mm (Foil) + 2 × 12 × 0.4mm = 39.6mm
  UV-Streifen-Breite = π × 40mm + 50mm ≈ 176mm (typisch 150–200mm)
```

**Farbwahl:**
- Marineblau und Schwarz: Beste UV-Absorption, aber heizen Segel auf
- Grau: Guter Kompromiss UV-Schutz / Waerme
- Weiss: Geringster UV-Schutz, aber kuehlt am besten
- AYDI-Empfehlung: Mittelgrau oder Anthrazit fuer beste Langzeit-Performance

### 2.7 Segelform bei Reffung (Sail Shape When Reefed)

Ein fundamental wichtiger Aspekt von Rollreffanlagen: Die Segelform bei teilweiser Aufrollung ist deutlich schlechter als bei einem dedizierten, kleineren Segel.

**Probleme der Rollreff-Segelform:**

1. **Bauchverlagerung:** Das Profil des vollen Segels ist fuer volle Segelflaeche optimiert. Bei Reffung wandert der Bauch nach achtern, was Luv-Gierigkeit erzeugt
2. **Vorlieks-Durchhang:** Das reduzierte Segel kann die Vorstag-Spannung nicht mehr ausreichend unterstuetzen, das Vorstag haengt durch
3. **Lose Lagen:** Die inneren Wickellagen koennen Falten bilden, die als "Beulen" sichtbar sind
4. **Achterliek-Oeffnung:** Das Achterliek oeffnet sich unkontrolliert, da die Segeltuch-Spannung nicht mehr optimal verteilt ist

**Gegenmassnahmen (Segeldesign fuer Rollreffanlagen):**

| Massnahme | Beschreibung | Effekt |
|-----------|-------------|--------|
| Flacherer Schnitt | Weniger Bauch als bei Segel fuer konventionellen Wechsel | Bessere Form bei Reffung, aber weniger Power bei Leichtwind |
| UV-Patch-Polster (Padding) | Schaumstoff-Pads am Vorliek, die den Wickeldurchmesser gleichmaessig vergroessern | Gleichmaessigeres Profil beim Rollen |
| Vertikale Latten (Vertical Battens) | Kurze Latten im Achterliek, die durch Rollschlitze gefuehrt werden | Bessere Achterliek-Kontrolle bei Reffung |
| Hollow Leech | Konvexes Achterliek (statt gerader oder konkaver Linie) | Achterliek oeffnet sich weniger |
| Reef-Stripes | Farbige Markierungen fuer optimale Reff-Positionen (1/3, 2/3) | Konsistente Reffpunkte fuer die Crew |

### 2.8 Fall-Spannung und ihre Auswirkungen (Halyard Tension Effects)

Die Halyard-Spannung (Fall-Spannung) hat einen dreifachen Einfluss auf die Funktion der Rollreffanlage:

**1. Vorstag-Spannung:**
- Bei Rollreffsystemen wird die Vorstag-Spannung primaer durch das Achterstag und den Masttrimm eingestellt
- Das Fall (Halyard) laeuft zum oberen Wirbel (Top Swivel) und haelt das Segel oben
- Zu wenig Fall-Spannung = Segel rutscht am Foil herunter, Falten am Kopf
- Zu viel Fall-Spannung = Erhoehte Reibung im oberen Wirbel, erschwertes Ein-/Ausrollen

**2. Luff-Tension und Segelform:**
- Fall-Spannung strafft das Vorliek und verschiebt den Segelbauch nach vorne
- Bei Rollreffen: Fall-Spannung vor dem Reffen leicht loesen, dann nach Reffung nachspannen
- Faustformel: Fall-Tension bei Reffung = 70–80% der Vollsegel-Tension

**3. Einfluss auf Rollwiderstand:**
- Hohe Fall-Spannung erhoehte Reibung im Top-Swivel-Lager
- Bei Selden Furlex: empfohlene max. Fall-Spannung 2.500–5.000 N (je nach Groesse)
- Bei Profurl: empfohlene max. Fall-Spannung 3.000–8.000 N
- Ueberschreitung fuehrt zu Lager-Verschleiss und erschwertem Furling

**Fall-Spannungs-Tabelle (Richtwerte):**

| Bootgroesse | Fall-Spannung Leichtwind (N) | Fall-Spannung Starkwind (N) | Max. Spannung Top Swivel (N) |
|------------|-----------------------------|-----------------------------|------------------------------|
| 25–30 ft | 600–1.000 | 1.500–2.500 | 3.000–4.000 |
| 30–36 ft | 1.000–1.800 | 2.500–4.000 | 4.500–6.000 |
| 36–42 ft | 1.500–2.500 | 3.500–5.500 | 6.000–9.000 |
| 42–50 ft | 2.000–3.500 | 5.000–8.000 | 9.000–14.000 |
| 50–60 ft | 3.000–5.000 | 7.000–12.000 | 14.000–22.000 |

### 2.9 Torsionskraefte und Anti-Torsion

Beim Einrollen eines Segels entstehen Torsionskraefte, die das Vorstag verdrillen. Dies ist besonders relevant bei:
- Code-0-Furlern (kein Profilfoil als Versteifung)
- Gennaker-Furlern (kein tragendes Vorstag)
- Trommelosen Continuous-Line-Systemen

**Anti-Torsion-Massnahmen:**

| Massnahme | Prinzip | Einsatz |
|-----------|---------|---------|
| Anti-Torsion-Seil (ATR) | Geflochtenes Seil mit gegenlaeufigen Litzen verhindert Verdrillung | Code 0, Gennaker |
| Swivel-Kette | Kugellager-bestuecter Wirbel am Segelkopf und -fuss | Alle Furler |
| Profilfoil-Versteifung | Foil nimmt Torsion auf und verhindert lokale Verdrillung | Standard-Cruising-Furler |
| Luff-Tape-Vorspannung | Vorgespanntes Vorliekband reduziert Torsionsverformung | Racing-Furler |

**Anti-Torsion-Seil-Spezifikation:**

| Material | Bruchlast (kN) | Gewicht (g/m) | Dehnung bei 30% BL | Typischer Einsatz |
|----------|----------------|---------------|---------------------|-------------------|
| Dyneema SK78 | 15–80 | 20–120 | <1% | Code 0, Performance |
| Technora/Twaron | 12–60 | 25–130 | <1.5% | Code 0, Cruising |
| PBO/Zylon | 20–100 | 15–90 | <0.5% | Superyacht, Grand Prix |
| Dyneema + Dacron Mantel | 10–50 | 30–150 | <2% | Cruising-Code-0 |

### 2.10 Vorstag-Durchhang und Segelperformance

Der Vorstag-Durchhang (Forestay Sag) ist einer der kritischsten Faktoren fuer die Segelperformance am Wind und wird durch die Rollreffanlage direkt beeinflusst.

**Ursachen fuer Vorstag-Durchhang:**
- Segeldruck auf das Vorsegel (Hauptursache)
- Unzureichende Achterstag-Spannung
- Mastbiegung (Mast biegt nach achtern, Vorstag wird entlastet)
- Gewicht der Furler-Anlage am Vorstag (sekundaer)
- Temperatur (Stahl dehnt sich bei Waerme)

**Auswirkung auf die Segelform:**
```
Vorstag ohne Durchhang:       Vorstag mit Durchhang:
  │                              ╲
  │ Segel flach,                  ╲ Segel bauchig,
  │ guter Hoehenlauf               ╲ schlechter Hoehenlauf
  │ effiziente Stroemung            ╲ fruehe Stroemungsabloesung
  │                                  ╲
  │                                   ╲
```

**Messung des Vorstag-Durchhangs:**

| Bootgroesse | Akzeptabler Durchhang (mm) | Guter Durchhang (mm) | Racing-Optimum (mm) |
|------------|--------------------------|---------------------|---------------------|
| 25–30 ft | 80–120 | 40–80 | <40 |
| 30–36 ft | 100–160 | 50–100 | <50 |
| 36–42 ft | 120–200 | 60–120 | <60 |
| 42–50 ft | 150–250 | 80–150 | <80 |
| 50–60 ft | 200–350 | 100–200 | <100 |

**Gegenmassnahmen:**
1. Achterstag spannen (effektivste Massnahme)
2. Rueckverstager (Checkstays/Runners) einsetzen (bei Regattayachten)
3. Mastbiegung kontrollieren (Babystag, Salingsdurchstellung)
4. Leichtere Furler-Anlage waehlen (weniger Gewicht am Vorstag)
5. Vorstag-Laenge korrekt einstellen (nicht zu lang!)

### 2.11 Rollreff-Segeldesign — Detaillierte Konstruktionsmerkmale

Das Design eines Rollreff-Segels unterscheidet sich fundamental von einem konventionellen Segel:

**Paneel-Layout:**

| Merkmal | Konventionelles Segel | Rollreff-Segel |
|---------|----------------------|---------------|
| Bauchtiefe | 12–16% der Sehnentiefe | 8–12% der Sehnentiefe |
| Bauchposition | 38–42% von der Nase | 35–40% von der Nase |
| Twist | Normal (10–15°) | Reduziert (8–12°) |
| Achterliek-Hohlkeit | Positiv (konvex) | Neutral bis leicht positiv |
| Vorliek-Spannung | Standard | Erhoehe (fuer Padding-Kompensation) |
| Latten | Normal (horizontal) | Vertikal oder keine (muessen rollen!) |

**Padding-Systeme:**

Padding (Vorliek-Polsterung) ist eine Schaumstoff- oder Tuchlage am Vorliek, die den Wickeldurchmesser gleichmaessiger macht:

| Padding-Typ | Beschreibung | Dicke | Anwendung |
|------------|-------------|-------|-----------|
| UV-Foam-Pad | Geschlossenporiger PVC-Schaum, aufgenaeht | 3–6mm | Standard Cruising |
| Dacron-Strip-Pad | Mehrere Dacron-Lagen uebereinandergenaeht | 2–4mm | Budget |
| Airex-Pad | Airex-Schaum, formgepresst | 4–8mm | Performance |
| Kein Padding | — | 0mm | Racing (Segel wird nicht gerefft) |

```
Querschnitt Vorliek MIT Padding:

    ┌─── UV-Streifen (Sunbrella)
    │ ┌─ Segeltuch (Dacron)
    │ │┌ Padding (Schaum)
    │ ││╭─ Luff Tape
    ▼ ▼▼▼
    ═╪╪╪╪═══════════ Segelflaeche
      ╰──╯
       ╰── Foil-Nut
```

### 2.12 Reffstrategien und Windstaffeln

**Empfohlene Reffstaffelung fuer Rollreff-Genuas:**

| Windstaerke (kn TWS) | Reffgrad | Verbleibende Segelflaeche | Segel-Bezeichnung |
|----------------------|---------|--------------------------|-------------------|
| 0–12 | 0% (voll) | 100% | Volle Genua |
| 12–18 | 15–20% | 80–85% | Leicht gerefft |
| 18–22 | 30–35% | 65–70% | Erstes Reff |
| 22–27 | 45–55% | 45–55% | Zweites Reff |
| 27–32 | 60–70% | 30–40% | Drittes Reff (Sturmfock-Groesse) |
| 32+ | 80–100% | 0–20% | Fast eingerollt oder ganz eingerollt |

**Kritische Hinweise zum Reffen:**
- IMMER in LEE reffen (Segel zum Wind hin einrollen)
- Schoten beim Reffen leicht unter Spannung halten (10–15% der Normalkraft)
- Fall-Spannung nach jedem Reff nachregulieren
- Bei Starkwind >30 kn: Segel KOMPLETT einrollen und Sturmfock am Innenstag setzen (falls vorhanden)
- Niemals ein stark gerefftes Rollsegel als Sturmfock-Ersatz verwenden — die Segelform ist zu schlecht

## 3. Typenuebersicht

### 3.1 Continuous-Line-Furler

**Prinzip:**
Beim Continuous-Line-Furler (Endlosleinenfurler) laeuft die Furler-Leine endlos ueber eine Umlenkrolle und zurueck zur Trommel. Es gibt keine konventionelle Wickeltrommel — die Leine laeuft bei jeder Umdrehung durch das gleiche Stueck Leine.

**Funktionsweise:**
- Leine laeuft von der Trommel zu einer Umlenkrolle am Mastfuss oder Cockpit und wieder zurueck
- Vorteil: Keine Wickeltrommel noetig, die voll wird
- Egal wie viel Segel ein- oder ausgerollt wird — die Leinenlaenge aendert sich nicht
- Die Leine kann direkt ueber eine Winsch gefahren werden

**Vorteile:**
- Kein Leinensalat in der Trommel
- Unbegrenzte Umdrehungen moeglich
- Direkte Winschbedienung moeglich
- Geringeres Gewicht (keine grosse Trommel)
- Bessere Kontrolle beim Reffen

**Nachteile:**
- Komplexere Leinenfuehrung (mehr Umlenkbloecke)
- Erfordert Slip-Ring oder Drehverteiler an der Trommel
- Hoehere Reibung durch mehr Umlenkungen
- Teurere Leinenfuehrung

**Typische Produkte:**
- Facnor LS/LX Serie (Continuous-Line-Option)
- Harken MKIV (Continuous-Line-Option)
- Profurl NEX (Continuous-Line-Option)

**Einsatzbereich:**
- Regattayachten ab 35 Fuss
- Performance-Cruiser mit Cockpit-Bedienung
- Kurzhand-Segler (weniger Leinenchaos)

### 3.2 Top-Down-Furler

**Prinzip:**
Der Top-Down-Furler (von oben nach unten rollend) rollt das Segel vom Kopf her ein — das Gegenteil zum konventionellen Furler, der von unten nach oben rollt. Entwickelt fuer Gennaker und asymmetrische Spinnaker, deren Unterliek frei steht.

**Funktionsweise:**
- Segel wird an einem Anti-Torsion-Seil (kein festes Vorstag) gesetzt
- Furler-Mechanismus sitzt am Segelkopf (Masttop oder Halyard)
- Beim Einrollen dreht die Furler-Leine den oberen Teil — das Segel rollt sich von oben nach unten auf
- Unten bleibt ein Tacker/Schot-Punkt mit freiem Unterliek

**Vorteile:**
- Perfekt fuer freistehende Segel (Gennaker, Asymmetric Spinnaker)
- Kein Vorschiff-Einsatz noetig zum Bergen
- Kontrolliertes Bergen auch bei Starkwind moeglich
- Segel bleibt am Kopf eingerollt — schnelles Wiedersetzen

**Nachteile:**
- Nicht fuer Reffen geeignet (nur 0% oder 100%)
- Anti-Torsion-Seil als zusaetzliche Komponente noetig
- Hoehere Kosten als einfache Berge-Systeme (Socks)
- Gewicht am Masttop (Stampfbewegung)

**Typische Produkte:**
- Facnor FX+ Serie (Top-Down-Furler)
- Karver KF Serie (Top-Down)
- Selden GX Serie
- Profurl Spin (Top-Down fuer Spinnaker)

**Einsatzbereich:**
- Fahrtenyachten mit Gennaker ab 32 Fuss
- Offshore-Racer (IMOCA, Class40, Mini 6.50)
- Mehrrumpfboote (Katamarane, Trimmarane)
- Kurzhandsegler, die allein Spinnaker segeln wollen

### 3.3 Under-Deck-Furler

**Prinzip:**
Die Trommel und der Antriebsmechanismus befinden sich unter Deck. Die Foilsektion beginnt auf Decksniveau, und alle mechanischen Komponenten sind unsichtbar.

**Funktionsweise:**
- Vorstag fuehrt durch eine Decksdurchfuehrung nach unten
- Trommel (meist elektrisch oder hydraulisch angetrieben) sitzt im Vorschiff
- Furler-Leine entfaellt vollstaendig — Steuerung ueber Motor
- Profilfoile beginnen auf Decksniveau

**Vorteile:**
- Optisch sauberes Deck (kein sichtbarer Furler-Mechanismus)
- Trommel geschuetzt vor Seewasser und UV
- Hohe Leistung (kein Leinenreibungsverlust)
- Perfekte Integration in Decksdesign

**Nachteile:**
- Hohe Kosten (€5.000–€30.000+ je nach Groesse)
- Aufwaendige Installation (Decksdurchfuehrung, Verstaerkung)
- Wartung unter Deck (eingeschraenkter Zugang)
- Nur bei Neubau oder aufwaendiger Nachruestung moeglich
- Abhaengigkeit von Elektrik/Hydraulik

**Typische Produkte:**
- Reckmann Under-Deck Serie
- Lewmar Under-Deck Furler
- Facnor Under-Deck-Varianten
- Custom-Loesungen von Rigg-Spezialisten

**Einsatzbereich:**
- Superyachten ab 50 Fuss
- Design-orientierte Yachten (Wally, Baltic, CNB)
- Neubauten mit Clean-Deck-Konzept

### 3.4 Elektrischer Furler

**Prinzip:**
Ein Elektromotor (DC oder AC) treibt die Trommel ueber ein Getriebe an. Die Bedienung erfolgt per Knopfdruck vom Cockpit, Steuerstand oder Fernbedienung.

**Funktionsweise:**
- Elektromotor (12V, 24V oder 48V DC; 230V AC bei Superyachten) ist an der Trommel oder unter Deck montiert
- Planetengetriebe oder Schneckengetriebe uebersetzen die Motordrehzahl auf die benoetigte Trommel-Drehzahl
- Endschalter oder Positionssensoren begrenzen die Auf-/Abrollung
- Steuerung ueber Taster, Touchscreen oder Autopilot-Integration
- Notfall-Handbedienung ueber Kurbel oder Leine muss vorhanden sein

**Vorteile:**
- Keine koerperliche Anstrengung
- Praezise Positionierung (Reff-Positionen speicherbar)
- Integration in Bordelektronik (NMEA 2000, CAN-Bus)
- Ideal fuer Kurzhand und Crew mit eingeschraenkter Mobilitaet
- Automatische Reffprogramme moeglich

**Nachteile:**
- Hohe Kosten (Aufpreis €2.000–€15.000 gegenueber manuell)
- Stromverbrauch (typisch 30–80A bei 12V waehrend Betrieb)
- Abhaengigkeit von Elektrik (Notfall-Manualbetrieb noetig)
- Zusaetzliches Gewicht (Motor, Getriebe, Kabel)
- Komplexere Wartung (Elektrik + Mechanik)

**Typische Produkte:**
- Reckmann e-Furler Serie (Marktfuehrer Superyachten)
- Facnor FXe Serie
- Selden Furlex E-Serie (Nachruestung)
- Harken Electric Furler
- Profurl ECI Serie

**Stromverbrauch-Tabelle:**

| Bootgroesse | Motorleistung (W) | Strom bei 12V (A) | Strom bei 24V (A) | Betriebszeit pro Reffvorgang (s) |
|------------|-------------------|-------------------|-------------------|----------------------------------|
| 30–36 ft | 300–500 | 25–42 | 12–21 | 15–25 |
| 36–42 ft | 500–800 | 42–67 | 21–33 | 20–35 |
| 42–50 ft | 800–1.500 | 67–125 | 33–63 | 25–45 |
| 50–60 ft | 1.500–3.000 | 125–250 (24V: 63–125) | 63–125 | 30–60 |
| 60–80 ft | 3.000–6.000 | — (nur 24V/48V) | 125–250 (oder 48V: 63–125) | 40–90 |

**Einsatzbereich:**
- Fahrtenyachten ab 40 Fuss
- Superyachten (Standard ab 55 Fuss)
- Kurzhand-Segler (Einhand-Atlantik, etc.)
- Charter-Yachten (einfachere Bedienung fuer Gaeste)

### 3.5 Manueller Furler (Standard Cruising)

**Prinzip:**
Der klassische Rollreffsystem-Furler mit Trommel am Vorschiff und Furler-Leine, die ueber Umlenkbloecke ins Cockpit gefuehrt wird. Rein mechanisch, angetrieben durch Muskelkraft ueber die Furler-Leine.

**Funktionsweise:**
- Furler-Leine wickelt sich auf die Trommel
- Trommel dreht die Foilsektionen und damit das Vorstag-System
- Segel rollt sich auf
- Leine wird am Cockpit-Beleger oder Klampe belegt

**Vorteile:**
- Zuverlaessig und einfach (wenige Verschleissteile)
- Guenstigste Loesung (€500–€3.000 je nach Groesse)
- Kein Strombedarf
- Leichtes Gewicht
- Einfache Wartung (jaehrlich Lager fetten, Foil-Verbindungen pruefen)

**Nachteile:**
- Koerperliche Anstrengung bei grossem Segel und Starkwind
- Weniger praezise Reff-Positionierung
- Leinenfuehrung kann komplex sein (Umlenkbloecke, Verklemmungsgefahr)
- Bei Starkwind: Furler-Leine kann aus den Haenden rutschen

**Typische Produkte:**
- Selden Furlex 20S bis 300S (Komplettsortiment)
- Facnor LS Serie (Standard Cruising)
- Profurl C-Serie (Classic Cruising)
- Harken MKIV Cruising
- Antal Furler-Serie

**Einsatzbereich:**
- Alle Fahrtenyachten 20–55 Fuss
- Budget-orientierte Eigner
- Yachten mit begrenzter Elektrik-Kapazitaet
- Langfahrt-Segler (Einfachheit = Zuverlaessigkeit)

### 3.6 Code-0-Furler

**Prinzip:**
Spezialisierter Furler fuer das Code-0-Segel (auch: Screecher, Reacher). Das Code 0 ist ein flach geschnittenes, grosses Vorsegel fuer Raumschots- und Halbwindkurse in leichtem bis mittlerem Wind. Es wird an einem separaten, abnehmbaren Furler gesetzt — nicht am Hauptvorstag.

**Funktionsweise:**
- Separates Anti-Torsion-Seil als "Vorstag" (kein festes Stahlvorstag)
- Segel mit Luff Tape am Anti-Torsion-Seil befestigt
- Trommel am Bugbeschlag (Tack-Fitting), Swivel am Segelkopf
- Furler-Leine rollt das Segel ein — dabei dreht sich das Anti-Torsion-Seil mit
- Bei eingerolltem Segel: Anti-Torsion-Seil bleibt unter Spannung stehen oder wird zusammen abgeschlagen

**Code-0-Furler vs. Genua-Furler:**

| Merkmal | Code-0-Furler | Genua-Furler |
|---------|--------------|--------------|
| Vorstag | Anti-Torsion-Seil (abnehmbar) | Festes Stahlvorstag (1×19) |
| Foilprofil | Kein Foil oder leichtes Foil | Aluminium-Profilfolie |
| Reffen | Nicht vorgesehen (nur Bergen) | Stufenloses Reffen |
| Gewicht | 2–8 kg | 5–25 kg |
| Montage | Abnehmbar, fuer den Einsatz gesetzt | Permanent installiert |
| Segelform | Sehr flach, laminiert | Cruising-Profil, Dacron |
| Windbereich | 4–18 kn (TWS) | 0–35+ kn |

**Typische Produkte:**
- Karver KF0.7 bis KF5 (Marktfuehrer Code-0-Furler)
- Facnor FX+700 bis FX+4000
- Selden Code 0 Furler GX
- Profurl Spin 1.5 bis Spin 8
- Harken Code 0 Furler MKIV

**Einsatzbereich:**
- Performance-Cruiser ab 30 Fuss
- Regattayachten (IRC, ORC, ORR)
- Offshore-Racer (IMOCA, Class40, Volvo Ocean Race)
- Mehrrumpfboote (Standard ab ca. 38 Fuss)

### 3.7 Asymmetric-Spinnaker-Furler

**Prinzip:**
Aehlich dem Code-0-Furler, aber dimensioniert fuer asymmetrische Spinnaker (A-Sails), die voller geschnitten sind und aus leichterem Tuch bestehen. Typisch als Top-Down-System ausgefuehrt.

**Funktionsweise:**
- Anti-Torsion-Seil am Vorliek, gesetzt am Bugspriet oder Bug
- Top-Down-Furler am Segelkopf (Masttop oder Top eines Hauptfalls)
- Einrollen von oben nach unten — Unterliek bleibt frei
- Leine laeuft vom Top-Mechanismus nach unten ins Cockpit
- Alternative: Bottom-Up-Systeme mit Trommel am Tack

**Asymmetric-Spinnaker-Furler vs. Code-0-Furler:**

| Merkmal | Asym-Spinnaker-Furler | Code-0-Furler |
|---------|-----------------------|--------------|
| Furling-Richtung | Top-Down (meist) | Bottom-Up (meist) |
| Segeltuch | Nylon, sehr leicht (0.5–1.5 oz) | Laminat, mittel (2–4 oz) |
| Segelform | Voll, bauchig | Flach, genua-aehnlich |
| Windbereich | 6–20 kn, Raumschots bis Vorwind | 4–18 kn, Halbwind bis Raumschots |
| Mechanismus | Oft Snuffer-aehnlich oder Drehwirbel | Trommel-basiert |
| Gewicht System | 1–5 kg | 2–8 kg |

**Typische Produkte:**
- Facnor FX+ Serie (Top-Down Spinnaker)
- Karver KFS Serie (Spinnaker Top-Down)
- Profurl Spin TD (Top-Down)
- Selden GX (Spinnaker-Variante)
- Ronstan RF Top-Down

**Einsatzbereich:**
- Fahrtenyachten ab 35 Fuss mit Gennaker
- Einhand- und Zweihand-Segler
- Regattayachten (Shorthanded Offshore)
- Katamarane und Trimmarane

### 3.8 Trommeltypen im Detail

**3.8.1 Offene Trommel (Open Drum)**

```
     ┌──────────────┐
     │  Foilsektion │
     │      │       │
   ──┼──────┼───────┼──
   │ │  ┌───┴───┐  │ │
   │ │  │ Lager │  │ │   Leine wickelt sichtbar
   │ │  └───┬───┘  │ │   auf die Trommel
   │ ╰═════╤═════╯ │ │
   │  Leine│→      │ │
   └───────┼───────┘ │
           ↓         │
      Zum Cockpit    │
```

- Einfachste Bauform
- Leine sichtbar auf Trommel gewickelt
- Probleme: Leine kann sich verklappen, UV-Exposition der Leine, Salzwasser-Kontakt mit Lagern
- Typisch bei: Aelteren Systemen, Budget-Furlern, kleinen Booten

**3.8.2 Geschlossene Trommel (Enclosed Drum)**

```
     ┌──────────────┐
     │  Foilsektion │
     │      │       │
   ──┼──────┼───────┼──
   │ ╔══════╧══════╗ │
   │ ║  ┌───────┐  ║ │   Komplett gekapselt
   │ ║  │ Lager │  ║ │   Schutz vor UV und Salz
   │ ║  └───┬───┘  ║ │
   │ ║ Leine│→     ║ │
   │ ╚══════╤══════╝ │
   └────────│────────┘
             ↓
        Zum Cockpit
```

- Standardbauform moderner Cruising-Furler
- Vollstaendig geschlossenes Gehaeuse
- Schutz vor UV, Salz, Schmutz
- Typisch bei: Selden Furlex, Facnor LS, Profurl C-Serie

**3.8.3 Continuous-Line-Mechanismus**

```
     ┌──────────────┐
     │  Foilsektion │
     │      │       │
   ──┼──────┼───────┼──
   │ ╔══════╧══════╗ │
   │ ║  Slip-Ring  ║ │   Leine laeuft endlos
   │ ║  ┌──┴──┐    ║ │   durch Slip-Ring
   │ ║  │Lager│    ║ │   Kein Wickeln auf Trommel
   │ ║  └──┬──┘    ║ │
   │ ╚═════╤═══════╝ │
   └───────│─────────┘
        ┌──┴──┐
        │Block│──→ Zum Cockpit ──→ Winsch ──→ Zurueck zur Trommel
        └─────┘
```

- Endlosleine: Leine laeuft von Trommel → Block → Cockpit → Winsch → zurueck zur Trommel
- Kein Wickelvorgang — Leine gleitet durch den Slip-Ring
- Unbegrenzte Umdrehungen moeglich
- Typisch bei: Regattabooten, Harken MKIV CL, Profurl NEX CL

**3.8.4 Under-Deck-Trommel**

```
   ═══════ Decksniveau ═══════
   │      ┌───────────┐      │
   │      │Decks-     │      │   Vorstag-Durchfuehrung
   │      │durchfuehr.│      │   durch Deck
   │      └─────┬─────┘      │
   │     ╔══════╧══════╗     │
   │     ║   Motor/    ║     │   Unter Deck montiert
   │     ║   Trommel   ║     │   Elektrisch oder hydraulisch
   │     ║   + Lager   ║     │
   │     ╚══════╤══════╝     │
   │            │             │
   │      Befestigung an     │
   │      Vorschiff-Struktur │
   └──────────────────────────┘
```

- Gesamter Mechanismus unter Deck
- Nur die Foilsektion ist sichtbar
- Meist elektrisch oder hydraulisch angetrieben
- Typisch bei: Superyachten (Reckmann, Lewmar UD)

**3.8.5 Captive-Reel-Trommel (Karver)**

```
     ┌──────────────┐
     │  ATR-Seil    │
     │      │       │
   ──┼──────┼───────┼──
   │ ╔══════╧══════╗ │

## 4. Dimensionierung und Auswahl

### 4.1 Primaere Dimensionierungsparameter

Die korrekte Groessenauswahl eines Furlers basiert auf drei Hauptparametern:

1. **Vorstag-Laenge (Forestay Length)** — Bestimmt die Foilsektions-Laenge und -Anzahl
2. **Vorstag-Drahtdurchmesser (Wire Diameter)** — Bestimmt die Foilggroesse (Innendurchmesser der Foilsektion muss zum Draht passen)
3. **Segelflaeche (Sail Area)** — Bestimmt die Trommelgroesse und Lagerbelastung

### 4.2 Vorstag-Laenge und Foilsektionen

**Foilsektions-Laenge:** Standardmaessig 2.0m oder 2.5m (je nach Hersteller). Die Gesamtlaenge wird durch Kombination von Standard-Sektionen plus einer kuerzbaren Anpassungssektion erreicht.

```
Vorstag-Laenge gesamt (L_vorstag)
= Abstand Masttopp-Befestigung → Bugbeschlag

Benoetigte Foil-Laenge (L_foil)
= L_vorstag - L_trommel_hoehe - L_top_swivel_hoehe - L_halyard_abstand

Typisch: L_foil ≈ L_vorstag × 0.92 bis 0.96

Anzahl Foilsektionen:
= ceil(L_foil / L_sektion)
```

## 6. Installation und Montage

### 6.1 Vorstag-Integration

**Variante A — Vorstag mit Profilfoil (Standard):**

Das bestehende Vorstag (1×19 Draht oder -stag mit Kompaktstrang) bleibt als tragendes Element. Die Profilfoile werden ueber das Vorstag geschoben.

**Installationsschritte:**

1. **Vorbereitung:** Vorstag-Laenge und -Durchmesser genau messen
2. **Foil-Laenge berechnen:** Vorstag-Laenge minus Trommelhoehe minus Swivel-Hoehe minus 50mm Toleranz
3. **Foilsektionen kuerzen:** Letzte Sektion auf Restmass kuerzen (Saege mit feinem Blatt, entgraten)
4. **Trommel am Fuss montieren:** Toggle-Verbindung am Bugbeschlag, Trommel ueber Vorstag-End-Fitting schieben
5. **Foilsektionen auffaedeln:** Von unten nach oben — Sektionen ueber Vorstag schieben und verbinden
6. **Top-Swivel montieren:** Oben am Vorstag-Kopf, unterhalb des Masttop-Beschlags
7. **Segel einfaedeln:** Luff Tape von unten in die Foilnut einfaedeln (Segel muss nach oben gleiten)
8. **Halyard anschlagen:** Fall am Top-Swivel befestigen, Spannung setzen
9. **Furler-Leine einfahren:** Leine auf Trommel, ueber Umlenkbloecke ins Cockpit fuehren
10. **Funktionstest:** Segel ein- und ausrollen, Leichtgaengigkeit pruefen

**Wichtige Toleranzen:**

| Parameter | Toleranz | Konsequenz bei Ueber-/Unterschreitung |
|-----------|---------|---------------------------------------|
| Foil-Laenge | ±10mm zur Berechnung | Zu lang: Swivel sitzt zu hoch, Foil kann Trommel beruehren. Zu kurz: Luecke am Top-Swivel |
| Vorstag-∅ im Foil | +0.5mm / -0mm | Zu eng: Foil laesst sich nicht montieren. Zu weit: Foil klappert |
| Trommel-Ausrichtung | <2° Achsabweichung | Schiefe Trommel fuehrt zu ungleichmaessiger Wicklung und Klemmern |
| Top-Swivel-Freigaengigkeit | 360° ohne Widerstand | Blockierter Swivel verhindert Einrollen |

**Variante B — Integraler Furler (Code 0, Gennaker):**

1. **Anti-Torsion-Seil am Tack-Fitting befestigen** (Bugspriet oder Bug-Beschlag)
2. **Furler-Trommel am Tack-Fitting montieren** (oder Captive-Reel-System)
3. **ATR-Seil auf volle Laenge auslegen** (Tack → Halyard-Block am Masttop)
4. **Segel anschlagen:** Tack am Furler-Drehpunkt, Head am Top-Swivel/Halyard
5. **Halyard setzen:** ATR-Seil unter Spannung bringen
6. **Furler-Leine einfahren:** Von Trommel ueber Umlenkbloecke ins Cockpit
7. **Funktionstest:** Ein-/Ausrollen unter Spannung, ohne und mit Wind

### 6.2 Trommelmontage

**Befestigungstypen:**

| Typ | Beschreibung | Bootgroesse | Montageaufwand |
|-----|-------------|------------|---------------|
| Stemhead-Toggle | Toggle am Bugbeschlag, Trommel dreht um Vorstag-Achse | Alle Groessen | Gering (Standard) |
| Deck-Mount | Trommel direkt auf Deck verschraubt | 25–45 ft | Mittel (Verstaerkung noetig) |

```

### 6.3 Leinenfuehrung (Line Routing)

Die Furler-Leine muss von der Trommel am Bug sicher und reibungsarm ins Cockpit gefuehrt werden.

**Standard-Leinenfuehrung:**

```
Trommel (Bug)
  │
  ↓ Leine laeuft auf Deck
  │
  ├→ Umlenkblock 1 (Bug-Bereich, seitlich)
  │
  ├→ Umlenkblock 2 (Mittschiff, an Fussreling oder Schiene)
  │
  ├→ Optional: Umlenkblock 3 (Cockpit-Eingang)
  │
  ├→ Klemme/Beleger am Cockpit
  │
  └→ Optional: Weiter zur Winsch (fuer Starkwind)
```

**Leinenfuehrungs-Regeln:**

1. **Maximaler Umlenkwinkel pro Block:** 120° (besser <90°)
2. **Minimaler Blockdurchmesser:** 8× Leinendurchmesser
3. **Leine darf nicht am Deck scheuern** — Decksdurchfuehrungen oder Bullaugen-Bloecke verwenden
4. **Furler-Leine nie ueber scharfe Kanten fuehren** — Kanten verrunden oder Leinen-Protektoren verwenden
5. **Restleine am Cockpit-Beleger:** Min. 3m Restleine, aufgeschossen, damit bei Starkwind nachgegeben werden kann
6. **Leinendurchmesser:** Typisch 6–10mm fuer Cruising, 4–8mm fuer Racing

**Furler-Leinen-Spezifikation:**

| Bootgroesse | Leinendurchmesser (mm) | Leinentyp | Laenge (m) |
|------------|----------------------|-----------|-----------|
| 25–30 ft | 6–7 | Polyester geflochten | 15–20 |
| 30–36 ft | 7–8 | Polyester geflochten | 18–25 |
| 36–42 ft | 8–10 | Polyester oder Dyneema-Kern | 22–30 |
| 42–50 ft | 10–12 | Dyneema-Kern, Polyester-Mantel | 28–38 |
| 50–60 ft | 12–14 | Dyneema-Kern | 35–45 |

### 6.4 Fall-Management (Halyard Management)

**Problem:** Bei Rollreffsystemen bleibt das Halyard (Fall) permanent am Top-Swivel. Wenn das Segel aufgerollt ist, muss das Fall gespannt bleiben, damit der Swivel nicht herunterfaellt und das Foilsystem stabil bleibt.

**Loesungen:**

| Loesung | Beschreibung | Vorteile | Nachteile |
|---------|-------------|----------|-----------|
| Halyard-Lock (Mast) | Mechanische Arretierung am Mast, haelt Fall in Position | Kein dauerhafter Zug auf Fall-Winsch, Winsch frei fuer anderes | Erfordert Mast-Modifikation, Nachruest-Aufwand |
| Halyard am Fall-Beleger | Fall wird nach Setzen des Segels am Mastfuss-Beleger belegt | Einfach, kein Umbau | Beleger permanent besetzt, Fall kann rutschen |
| Halyard auf Winsch | Fall wird auf einer dedizierten Winsch gehalten | Feinjustierung moeglich, hohe Haltekraft | Winsch permanent besetzt |
| Selden/Facnor Halyard-Deflector | Spezial-Umlenkung am Masttop, die Fall um 180° umlenkt | Saubere Fallfuehrung, reduzierte Reibung | Herstellerspezifisch |

**Halyard-Wrap-Verhuetung:**

Das Fall darf sich NICHT um das Vorstag/Foil wickeln. Dies ist einer der haeufigsten Fehler und fuehrt zur Blockierung des Furlers.

Praeventionsmassnahmen:
- Halyard-Patch am Masttop (Kunststoff- oder Edelstahl-Ablenkung)
- Korrekte Fall-Fuehrung (Fall muss IMMER hinter dem Vorstag laufen, nie seitlich)
- Fall-Spannung halten, auch bei aufgerolltem Segel
- Halyard-Lock verwenden (best practice)

### 6.5 Spezielle Installationsszenarien

**6.5.1 Nachruestung bei Aluminium-Mast mit internem Vorstag:**

Bei vielen aelteren Yachten (z.B. Hallberg-Rassy, Malo, Najad) laeuft das Vorstag intern durch den Mast. Die Rollreffanlage wird dann wie folgt installiert:

1. Mast-internes Vorstag am Masttopp durch Mastöffnung nach aussen fuehren
2. Trommel am externen Bugbeschlag montieren
3. Foilsektionen ueber das externe Vorstag-Stueck schieben
4. ACHTUNG: Das interne Vorstag-Stueck im Mast bleibt unberuehrt — nur der externe Teil erhaelt Foils

**6.5.2 Installation bei doppeltem Vorstag:**

Einige Yachten haben ein Hauptvorstag und ein Innenstag (Babystag/Solent Stay). Die Rollreffanlage wird typisch am Hauptvorstag installiert:

```
Masttop
  ├── Hauptvorstag (mit Furler) ──→ Bugbeschlag
  │     Genua/Fock auf Rollreff
  │
  └── Innenstag (ohne Furler) ──→ Mastfuss oder Schiene auf Deck
        Sturmfock oder Solent-Fock (Stagreiter/Hank-on)
```

Vorteile der Doppel-Vorstag-Konfiguration:
- Rollreff fuer Normalerwind auf Hauptvorstag
- Sturmfock auf Innenstag bei Starkwind (>30 kn)
- Keine Abhaengigkeit vom Rollreff-System bei Starkwind
- Empfehlung fuer CE-Kategorie A (Ocean)

**6.5.3 Code-0-Furler am Bugspriet:**

```
                    Bugspriet
                   ╱        ╲
                  ╱    Tack   ╲
    ┌────────────╱──Fitting────╲──────────┐
    │       Bugspriet-Ende      │          │
    │    ┌───────────────┐      │          │
    │    │ Code-0-Furler │      │          │
    │    │ Trommel       │      │          │
    │    └───────┬───────┘      │          │
    │            │              │          │
    └────────────│──────────────┘          │
                 │ ATR-Seil                │
                 │ (zum Masttop)           │
                 │                         │

```

Installationshinweise:
- Bugspriet muss fuer die Tack-Last dimensioniert sein (typisch 2–5 kN)
- Furler-Leine vom Bugspriet-Ende ueber Umlenkblock am Bug ins Cockpit
- ATR-Seil-Laenge = Bugspriet-Laenge + Masttop-Hoehe + 10% Reserve
- Tack-Fitting: Drehbar (Wirbel), damit ATR-Seil frei drehen kann

## 7. Fehlerbild-Atlas

### Fehlerbild F15.01 — Trommelklemmer (Drum Jam)

**Symptom:** Furler-Leine laesst sich weder einholen noch fieren. Trommel dreht sich nicht.

**Haeufigkeit:** Hoch (25% aller Furler-Probleme)

**Ursachen:**

| Nr. | Ursache | Wahrscheinlichkeit | Schweregrad |
|-----|---------|-------------------|-------------|
| 1 | Furler-Leine hat sich in der Trommel verklemmt (Override) | 40% | Mittel |
| 2 | Lager-Korrosion (Festfressen) | 25% | Hoch |
| 3 | Fremdkoerper in der Trommel (Sand, Muscheln, Segel-Fetzen) | 20% | Niedrig |
| 4 | Foil-Verbindung hat sich geloest und blockiert Drehung | 10% | Mittel |
| 5 | Fall hat sich um Foil/Vorstag gewickelt (Halyard Wrap) | 5% | Hoch |

**Diagnose:**
1. Visuell: Trommel von aussen inspizieren — ist die Leine sauber gewickelt?
2. Manuell: Versuchen, Trommel von Hand zu drehen (bei gefierten Schoten)
3. Lager pruefen: Trommel abnehmen, Lager auf Leichtgaengigkeit pruefen
4. Foil inspizieren: Verbindungsstellen sichtbar pruefen
5. Masttop pruefen: Halyard-Wrap am oberen Swivel sichtbar?

**Behebung:**
- Override: Leine abwickeln, Trommel reinigen, Leine sauber neu einlegen
- Lager: Lager reinigen und fetten (Winsch-Fett oder Teflon-Spray). Bei Festfressen: Lager ersetzen
- Fremdkoerper: Trommel oeffnen, reinigen, ggf. mit Suesswasser spuelen
- Foil-Verbindung: Verbinder ersetzen oder nachziehen
- Halyard Wrap: Fall loesen, ggf. Mast besteigen. Fall-Deflector nachrüsten

**Confidence:** documented (Hersteller-Servicedaten, Werftberichte)

---

### Fehlerbild F15.02 — UV-Streifen-Versagen (UV Strip Failure)

**Symptom:** UV-Schutzstreifen reisst, loest sich, oder zeigt Durchscheinen des Segeltuches darunter. Segel zeigt vorzeitige UV-Degradation.

**Haeufigkeit:** Mittel-Hoch (20% aller Furler-Probleme, besonders Mittelmeer)

**Ursachen:**

| Nr. | Ursache | Wahrscheinlichkeit | Schweregrad |
|-----|---------|-------------------|-------------|
| 1 | Natuerliche UV-Alterung (Lebensdauerende) | 40% | Mittel |
| 2 | Minderwertige Naht (Naht loest sich vor Tuch-Versagen) | 25% | Mittel |
| 3 | Falsche UV-Streifen-Breite (Segel scheint durch) | 15% | Hoch |
| 4 | Mechanische Beschaedigung (Scheuern an Reling, Wanten) | 10% | Niedrig |
| 5 | Falsches Material (Dacron statt Sunbrella, keine UV-Behandlung) | 10% | Hoch |

**Diagnose:**
1. Visuell: Segel vollstaendig ausrollen, UV-Streifen auf gesamter Laenge inspizieren
2. Zugtest: An verschiedenen Stellen am UV-Streifen ziehen — reisst er leicht?
3. Breite messen: Segel einrollen, pruefen ob Segeltuch sichtbar bleibt
4. Naht inspizieren: Nahtbild pruefen — Fadenverfaerbung, offene Stiche

**Behebung:**
- Lebensdauerende: UV-Streifen durch Segelmacher ersetzen lassen (€200–€600 je nach Groesse)
- Nahtversagen: Naht erneuern, ggf. mit UV-bestaendigem Faden (Tenax, Gore Tenara)
- Falsche Breite: Breiteren UV-Streifen aufnaehing lassen
- Materialaustausch: Sunbrella-Stoff verwenden (Referenz: Sunbrella Marine 46" oder Recacril)

**Praevention:**
- Segel-Persenning als zusaetzlichen Schutz verwenden (besonders im Mittelmeer)
- UV-Streifen alle 5 Jahre inspizieren und ggf. vorbeugend erneuern
- Hochwertiges UV-Stoff-Material von Anfang an waehlen

**Confidence:** documented (Segelmacher-Berichte, Material-Spezifikationen)

---

### Fehlerbild F15.03 — Foil-Verbindungstrennung (Foil Joint Separation)

**Symptom:** Sichtbare Luecke zwischen zwei Foilsektionen. Segel blockiert beim Ein-/Ausrollen an der Trennstelle. Klapperndes Geraeusch bei Seegang.

**Haeufigkeit:** Mittel (15% aller Furler-Probleme)

**Ursachen:**

| Nr. | Ursache | Wahrscheinlichkeit | Schweregrad |
|-----|---------|-------------------|-------------|
| 1 | Snap-Lock-Verbinder hat sich durch Vibration geloest | 35% | Mittel |
| 2 | Verbinder gebrochen (Ermuedung, Korrosion) | 25% | Hoch |
| 3 | Thermische Ausdehnung (Aluminium bei starker Sonneneinstrahlung) | 20% | Niedrig |
| 4 | Fehlerhafte Montage (Verbinder nicht vollstaendig eingerastet) | 15% | Mittel |
| 5 | Materialermuedung Foil (Riss im Foil an Verbindungsstelle) | 5% | Kritisch |

**Diagnose:**
1. Visuell: Segel voll ausrollen, gesamte Foillaenge inspizieren (ggf. Fernglas)
2. Akustisch: Beim Segeln auf Klappergeraeusche achten
3. Funktional: Segel langsam ein-/ausrollen — Blockade an bestimmter Stelle?
4. Taktil: Von Deck aus zugaengliche Verbindungsstellen auf Spiel pruefen

**Behebung:**
- Geloester Verbinder: Segel bergen, Foil demontieren, Verbinder einsetzen und sichern (Sicherungsschraube, Kabelbinder als Backup)
- Gebrochener Verbinder: Ersatzteil beim Hersteller bestellen, ersetzen
- Riss im Foil: Foilsektion komplett ersetzen (NICHT schweissen oder kleben — tragendes Bauteil!)

**Confidence:** documented (Hersteller-Serviceberichte)

### Fehlerbild F15.04 — Halyard Wrap

**Symptom:** Das Fall (Halyard) hat sich um das Vorstag/die Profilfolie gewickelt. Segel laesst sich weder ein- noch ausrollen. Fall laesst sich nicht mehr dichtholen oder fieren.

**Haeufigkeit:** Mittel (12% aller Furler-Probleme, haeufigster Notfall)

**Ursachen:**

| Nr. | Ursache | Wahrscheinlichkeit | Schweregrad |
|-----|---------|-------------------|-------------|
| 1 | Fall bei aufgerolltem Segel nicht gespannt gehalten | 40% | Hoch |
| 2 | Fall laeuft seitlich am Vorstag vorbei statt dahinter | 30% | Hoch |
| 3 | Fehlende Halyard-Deflector am Masttop | 20% | Mittel |
| 4 | Defekter Top-Swivel (dreht sich nicht frei) | 10% | Hoch |

**Diagnose:**
1. Visuell von Deck: Am Masttop schauen — ist das Fall sichtbar um das Foil gewickelt?
2. Fall ziehen: Laesst sich das Fall ueberhaupt bewegen?
3. Anzahl der Wraps: Wie oft hat sich das Fall um das Vorstag gewickelt? (bestimmt Schwierigkeit)

**Behebung:**
- 1–2 Wraps: Segel teilweise ausrollen, Fall in die Gegenrichtung "zurueckdrehen" (manchmal moeglich von Deck)
- 3+ Wraps oder Blockade: Mast besteigen oder Bosunchair verwenden, Fall manuell loesen
- Praevention: Halyard-Lock installieren, Fall-Deflector nachrüsten, IMMER Fallspannung halten

**Confidence:** documented (Regatta-Berichte, Notfall-Protokolle)

---

### Fehlerbild F15.05 — Swivel-Lagerschaden (Swivel Bearing Failure)

**Symptom:** Oberer Wirbel (Top Swivel) dreht sich nicht frei. Segel rollt schwergaengig ein, blockiert teilweise. Knirschende Geraeusche am Masttop.

**Haeufigkeit:** Mittel (10% aller Furler-Probleme)

**Ursachen:**

| Nr. | Ursache | Wahrscheinlichkeit | Schweregrad |
|-----|---------|-------------------|-------------|
| 1 | Korrosion der Lager (Salzwasser-Intrusion) | 35% | Hoch |
| 2 | Uebermaessige Halyard-Spannung hat Lager ueberlastet | 25% | Hoch |
| 3 | Normaler Verschleiss (Lebensdauer ueberschritten) | 20% | Mittel |
| 4 | Verschmutzung (Sand, Salzkristalle in Lager) | 15% | Mittel |
| 5 | Materialbedingter Lagerschaden (Fertigungsfehler, seltene Legierung) | 5% | Hoch |

**Diagnose:**
1. Akustisch: Knirschen oder Klicken am Masttop beim Rollen?
2. Funktional: Segel bei Leichtwind einrollen — geht es schwer, besonders am Anfang?
3. Visuell (Mastbesteigung): Swivel auf Korrosion, Spiel, Verfaerbung pruefen
4. Manuell: Swivel von Hand drehen — Ruckeln, Widerstand, Spiel?

**Behebung:**
- Leichte Verschmutzung: Suesswasser spuelen, mit Marine-Fett oder Teflon-Spray schmieren
- Korrodierte Lager: Lager-Kit tauschen (herstellerspezifisch, ca. €80–€250)
- Defekter Swivel: Komplett-Swivel ersetzen (€150–€500)
- Vorbeugung: Jaehrlich Swivel mit Suesswasser spuelen, alle 2 Jahre Lager pruefen

**Confidence:** documented (Hersteller-Wartungsplaene, Rigg-Werkstatt-Berichte)

---

### Fehlerbild F15.06 — Ungleichmaessiges Einrollen

**Symptom:** Segel rollt sich nicht gleichmaessig auf. Einige Bereiche sind straff gewickelt, andere lose. "Beulen" oder "Wuerste" im aufgerollten Segel.

**Haeufigkeit:** Mittel (10%)

**Ursachen:**

| Nr. | Ursache | Wahrscheinlichkeit |
|-----|---------|-------------------|
| 1 | Ungleichmaessige Schot-Spannung beim Einrollen | 30% |
| 2 | Halyard-Spannung zu hoch oder zu niedrig | 25% |
| 3 | Segel nicht fuer Rollreff-Einsatz geschnitten | 20% |
| 4 | Vorstag-Durchhang (Riggtrimm) | 15% |
| 5 | Foil-Verbindung verkantet | 10% |

**Behebung:**
- Schoten beim Einrollen leicht gefiert halten, aber nicht lose (ca. 10–15% der Einholkraft auf Schot)
- Fall-Spannung korrekt einstellen (siehe Abschnitt 2.8)
- Segel vom Segelmacher fuer Rollreff optimieren lassen (Padding, Flachschnitt)
- Achterstag spannen zur Reduzierung des Vorstag-Durchhangs

**Confidence:** estimated (Segeltrimm-Praxis)

---

### Fehlerbild F15.07 — Furler-Leine bricht/rutscht

**Symptom:** Segel rollt sich bei Starkwind unkontrolliert aus. Furler-Leine gebrochen oder von Beleger/Klemme gerutscht.

**Haeufigkeit:** Niedrig-Mittel (8%), aber SICHERHEITSKRITISCH

**Ursachen:**

| Nr. | Ursache | Wahrscheinlichkeit |
|-----|---------|-------------------|
| 1 | Leinenbruch durch UV-Alterung | 30% |
| 2 | Leine aus Klemme gerutscht (zu wenig Wraps, falsche Klemme) | 30% |
| 3 | Leinenbruch durch Scheuerung | 25% |
| 4 | Falsche Leinendimension (zu duenn) | 15% |

**Behebung (NOTFALL):**
- SOFORT: Wind aus dem Segel nehmen (Abfallen oder Aufluven)
- Notfalls Segel am Achterliek festhalten (Person am Vorschiff, gesichert!)
- Ersatzleine vorbereiten und in Trommel einlegen
- Langfristig: Furler-Leine alle 3–5 Jahre erneuern, auf Scheuerung pruefen

**Confidence:** documented (Seenotberichte, Versicherungsdaten)

---

### Fehlerbild F15.08 — Foil-Deformation

**Symptom:** Profilfoile sind verbogen oder eingedellt. Segel klemmt beim Rollen.

**Haeufigkeit:** Niedrig (5%)

**Ursachen:** Uebermaessige Vorstag-Spannung, Schlag gegen Mast/Reling, Transportschaden, Foil-Material ermuedung

**Behebung:** Leichte Verbiegung mit Vorsicht richten (Aluminium). Bei Dellen oder Knicken: Sektion ersetzen. Niemals weitersegeln mit deformierten Foils — Klemmgefahr!

**Confidence:** documented

---

### Fehlerbild F15.09 — Trommel-Lager-Geraemusche

**Symptom:** Klicken, Knirschen oder Rattern bei der Trommeldrehung.

**Haeufigkeit:** Mittel (10%)

**Ursachen:** Lager-Verschleiss, Korrosion, Verschmutzung, lose Lager-Vorspannung

**Behebung:** Trommel demontieren, Lager inspizieren, reinigen, fetten oder ersetzen. Trommel mit Suesswasser spuelen (regelmaessige Wartung!).

**Confidence:** documented

---

### Fehlerbild F15.10 — Segel klemmt im Foil

**Symptom:** Segel laesst sich nicht aus- oder einrollen. Luff-Tape blockiert in der Foilnut.

**Haeufigkeit:** Mittel (8%)

**Ursachen:** Uebergroesses Luff-Tape fuer den Foil, Fremdkoerper in der Nut, Korrosion/Rauigkeit in der Nut, Segel wurde bei nassem Zustand eingerollt (Quellen)

**Behebung:** Segel vorsichtig mit Schmiermittel (Silikon-Spray) in der Nut loesen. Foilnut reinigen. Luff-Tape-Abmessung pruefen. Segel nie nass einrollen!

**Confidence:** documented

---

### Fehlerbild F15.11 — Elektrischer Furler — Motorausfall

**Symptom:** Elektrischer Furler reagiert nicht auf Bedienung. Motor laeuft nicht an oder dreht sich langsam.

**Haeufigkeit:** Niedrig-Mittel bei E-Furlern (8%)

**Ursachen:** Sicherung durchgebrannt, Kabelverbindung korrodiert, Motorueberhitzung (Thermo-Schutz), Steuerungsdefekt, Batteriespannung zu niedrig

**Behebung:**
- NOTFALL: Manuellen Override aktivieren (jeder E-Furler MUSS manuellen Notbetrieb haben!)
- Sicherungen pruefen (Hauptsicherung am Motor + Nebensicherung an Verteilung)
- Kabelverbindungen auf Korrosion pruefen
- Batteriespannung messen (muss >11.5V bei 12V-System, >23V bei 24V-System sein)
- Motor auf Ueberhitzung pruefen (thermischer Schutzschalter — 15 min abkuehlen lassen)

**Confidence:** documented (Hersteller-Servicedaten)

---

### Fehlerbild F15.12 — Anti-Torsion-Seil-Versagen (Code 0 / Gennaker)

**Symptom:** Code-0-Segel laesst sich nicht einrollen, verdreht sich nur um sich selbst ohne aufzuwickeln. ATR-Seil zeigt sichtbare Verdrillung.

**Haeufigkeit:** Niedrig-Mittel bei Code-0-Systemen (10%)

**Ursachen:** ATR-Seil hat Anti-Torsion-Eigenschaft verloren (Alterung, UV), ATR-Seil zu lang (durchhaengend), Falscher ATR-Seil-Typ fuer den Furler, Beschaedigtes ATR-Seil (Schnitt, Scheuerung)

**Behebung:** ATR-Seil ersetzen (alle 5–8 Jahre oder bei sichtbarer Degradation). Korrekte Laenge und Typ mit Hersteller abgleichen. ATR-Seil unter Spannung lagern (nicht geknickt!).

**Confidence:** documented (Racing-Team-Berichte, Karver-Servicedaten)

### 8.7 Notfall-Szenarien und Handlungsanweisungen

**Szenario A: Rollreffanlage komplett blockiert bei 30+ kn Wind**

```
1. RUHE BEWAHREN — Boot ist manoevrierbar solange Segel steht
2. Auf Raumschotskurs gehen (Wind von achtern) — reduziert Segellast
3. Motor starten als Backup
4. Versuchen, Trommel manuell zu drehen (eine Person am Bug, gesichert!)
5. Wenn Trommel blockiert: Segel am Vorschiff manuell herunterziehen
   → Halyard loesen, Segel auf Deck ziehen, mit Leinen sichern
6. Unter Motor zum naechsten Hafen
7. An Land: Furler inspizieren und reparieren
```

**Szenario B: Furler-Leine reisst bei Starkwind, Segel entrollt sich unkontrolliert**

```
1. SOFORT AUFLUVEN (Bug in den Wind) → Wind aus dem Segel
2. Schoten dichthalten → Segel moeglichst am Flattern hindern
3. Ersatzleine vorbereiten (jeder Fahrtensegler sollte Ersatzleine bereithalten!)
4. Ersatzleine auf Trommel legen → einige Windungen aufwickeln
5. Segel erneut kontrolliert einrollen
6. Falls keine Ersatzleine: Segel manuell auf Vorschiff bergen (mit Sicherheitsgurt!)
```

**Szenario C: Halyard-Wrap bei Seegang — Segel weder ein- noch ausrollbar**

```
1. NICHT weiterdrehen — verschlimmert den Wrap
2. Segel in aktueller Position belassen und weitersegeln
3. Wind- und Seegang-Beruhigung abwarten
4. Bei ruhigerem Wetter: Mast besteigen (Bosun-Chair, 2. Person sichert)
5. Fall am Masttop loesen, Wrap manuell aufloesen
6. Falls Mastbesteigung nicht moeglich: naechsten Hafen anlaufen, Rigg-Kran nutzen
```

## 9. FAQ — 25 haeufig gestellte Fragen

### F1: Kann ich eine Rollreffanlage nachruesten?

**Antwort:** Ja, Nachruestung ist bei den meisten Yachten moeglich und eine der haeufigsten Nachruestungen ueberhaupt. Voraussetzungen: (a) Das bestehende Vorstag muss durch ein neues Vorstag mit passendem Durchmesser fuer die Foilsektionen ersetzt werden oder der bestehende Durchmesser passt zu einem Furler-Modell. (b) Am Bugbeschlag muss Platz fuer die Trommel sein. (c) Es muss eine Leinenfuehrung ins Cockpit geplant werden. Kosten fuer eine Komplettnachruestung (Furler + neues Vorstag + Montage) typisch: €1.500–€4.000 (30–40ft Cruiser).

**Confidence:** documented

### F2: Wie oft muss eine Rollreffanlage gewartet werden?

**Antwort:** Empfohlene Wartungsintervalle: (a) Jaehrlich: Trommel und Top-Swivel mit Suesswasser spuelen, Foil-Verbindungen auf Festigkeit pruefen, Furler-Leine auf Verschleiss pruefen. (b) Alle 2–3 Jahre: Trommel oeffnen, Lager inspizieren und fetten, Top-Swivel-Lager pruefen. (c) Alle 5–8 Jahre: Lager-Satz erneuern (vorbeugend), UV-Streifen pruefen und ggf. erneuern, Furler-Leine erneuern. (d) Alle 10–15 Jahre: Foilsektionen auf Korrosion und Verformung pruefen, ggf. ersetzen.

**Confidence:** documented

### F3: Ist eine Rollgenua genauso schnell wie ein Segelwechsel?

**Antwort:** Nein. Ein gerefftes Rollsegel hat immer eine schlechtere Segelform als ein dediziertes, korrekt geschnittenes Vorsegel der entsprechenden Groesse. Fuer Fahrten-Segler ist der Komfort- und Sicherheitsgewinn jedoch weit hoeher als der Geschwindigkeitsverlust (typisch 3–8% bei gerefft vs. korrektem kleinerem Segel). Regattasegler verwenden daher Rollreff primaer zum Bergen und setzen verschiedene Segel ueber Twin-Groove-Foils.

**Confidence:** estimated

### F4: Luff Wire oder Luff Tape — was ist besser?

**Antwort:** Luff Tape (Vorliekband) ist die modernere und ueberlegene Loesung fuer die meisten Anwendungen. Vorteile: Segel ist austauschbar, bessere Segelform durch Foil-Profilierung, Wartung des Vorstags moeglich ohne Segel. Luff Wire wird heute nur noch bei sehr kleinen Booten (<25 ft) oder Budget-Systemen eingesetzt. AYDI-Empfehlung: Luff Tape bei jedem Neukauf.

**Confidence:** documented

### F5: Welcher Furler-Hersteller ist der beste?

**Antwort:** Es gibt keinen "besten" Hersteller — die Wahl haengt vom Einsatzprofil ab. Empfehlungen: (a) Budget-Cruising (25–35 ft): Selden Furlex (bestes Preis-Leistungs-Verhaeltnis, riesiges Ersatzteil-Netz). (b) Performance-Cruising (30–45 ft): Harken MKIV oder Profurl NEX (leichter, aerodynamischer Foil). (c) Langfahrt (35–50 ft): Facnor LS (robust, weltweit verfuegbar). (d) Superyacht (50+ ft): Reckmann (deutsche Praezision, Electric/Hydraulisch). (e) Racing Code 0: Karver KF (leichtester, Captive-Reel).

**Confidence:** estimated

### F6: Wie dimensioniere ich die Furler-Leine?

**Antwort:** Furler-Leinen-Durchmesser: Typisch Vorstag-Durchmesser + 1mm als Richtwert. Mindestens 6mm (Handhabbarkeit). Laenge: Vorstag-Laenge × 1.2 + Cockpit-Distanz + 3m Reserve. Material: Polyester geflochten fuer Cruising, Dyneema-Kern fuer Racing. WICHTIG: Furler-Leine muss auf der Trommel nicht reiben — daher weichen, flexiblen Mantel waehlen.

**Confidence:** documented

### F7: Was kostet eine komplette Rollreffanlage (30-ft-Segelboot)?

**Antwort:** Grobe Kalkulation fuer ein 30-ft-Boot (Genua ~25 m², Vorstag 7mm × 12m): (a) Furler-System (Selden Furlex 100S): €1.400–€1.800. (b) Neues Vorstag mit Terminals: €250–€400. (c) Umlenkbloecke (2–3 Stueck): €80–€200. (d) Furler-Leine (25m): €40–€80. (e) Montage (Fachbetrieb): €400–€800. Gesamt: €2.200–€3.300. Bei Nachruestung kommt ggf. ein neues Rollreff-Segel hinzu: €1.500–€3.000 zusaetzlich.

**Confidence:** estimated

### F8: Mein Furler klemmt bei Starkwind — was kann ich tun?

**Antwort:** Sofortmassnahmen: (1) Nicht mit Gewalt ziehen — Lager und Leine koennen brechen! (2) Wind aus dem Segel nehmen: Aufluven oder Abfallen, bis Segel killt. (3) Halyard-Spannung leicht reduzieren. (4) Schot auf Lee-Seite leicht dichtholen, damit Segel etwas Profil bekommt. (5) Erneut Furler-Leine ziehen — jetzt sollte es leichter gehen. Falls nicht: Segel manuell auf dem Vorschiff bergen (Sicherheitsgurt!), dann an Land Furler inspizieren.

**Confidence:** documented

### F9: Kann ich einen Code-0-Furler am normalen Vorstag betreiben?

**Antwort:** Nein. Ein Code-0-Furler benoetigt ein separates Anti-Torsion-Seil und wird neben dem Vorstag gesetzt (typisch am Bugspriet oder an einem separaten Bug-Befestigungspunkt). Das Code-0-Segel wird NICHT in den normalen Genua-Furler eingefaedelt. Beide Systeme sind unabhaengig voneinander.

**Confidence:** measured

### F10: Wie erkenne ich, ob meine Lager verschlissen sind?

**Antwort:** Symptome: (a) Segel rollt schwergaengiger ein als frueher. (b) Knirschen oder Klicken beim Drehen der Trommel/des Swivels. (c) Sichtbares Spiel (Wackeln) der Trommel auf dem Vorstag. (d) Korrosion sichtbar (braune/rote Verfaerbung an Lagersitz). Test: Segel ausrollen, Furler-Leine loesen, Trommel von Hand drehen. Sie sollte leicht und gleichmaessig drehen. Jedes Knirschen, Rattern oder Blockieren = Lagerproblem.

**Confidence:** documented

### F11: Brauche ich einen UV-Schutzstreifen?

**Antwort:** Ja, zwingend, wenn das Segel aufgerollt am Vorstag verbleibt (Standard bei Fahrtenseglern). Ohne UV-Schutz wird Dacron-Segeltuch im Mittelmeer innerhalb von 2–3 Saisons sproed und reisst. Ausnahme: Wenn das Segel nach jedem Toern abgeschlagen wird (Racing) oder eine separate Segel-Persenning ueber das aufgerollte Segel gezogen wird.

**Confidence:** documented

### F12: Wie lagere ich das Segel im Winter — aufgerollt oder abgeschlagen?

**Antwort:** Optimale Winterlagerung: Segel ABSCHLAGEN, trocken einlagern (dunkel, belueftet). Aufgerollte Lagerung ueber den Winter ist akzeptabel, wenn: (a) UV-Schutzstreifen intakt, (b) Segel komplett trocken eingerollt, (c) Persenning ueber das aufgerollte Segel gezogen. NICHT akzeptabel: Nasses oder feuchtes Segel aufgerollt ueberwintern — Schimmelgefahr!

**Confidence:** documented

### F13: Was ist ein Twin-Groove-Foil?

**Antwort:** Ein Profilfoil mit zwei parallelen Segelnuten (Luff Grooves). Ermoeglicht das Setzen eines neuen Segels in die zweite Nut, waehrend das alte Segel noch in der ersten Nut steht. Dadurch: Segelwechsel unter Fahrt ohne komplettes Bergen. Typisch bei Regattayachten (Profurl NEX Twin-Groove, Facnor LX Twin-Groove). Fuer Fahrtensegler meist nicht noetig.

**Confidence:** measured

### F14: Kann ich jedes Segel auf einem Rollreffsystem verwenden?

**Antwort:** Nein. Rollreff-Segel muessen speziell geschnitten sein: (a) Flacherer Schnitt als konventionelle Segel. (b) UV-Schutzstreifen am Achter- und Unterliek. (c) Luff Tape, das exakt zum Foil passt (Breite und Material). (d) Optionale Vorliek-Polsterung (Padding) fuer gleichmaessiges Rollen. (e) Rollbar gemachte oder durchlaufende Latten. Ein Standard-Segel auf einem Rollreffsystem funktioniert schlecht bis gar nicht.

**Confidence:** documented

### F15: Was ist der Unterschied zwischen einem Furler und einem Reefing-System?

**Antwort:** Furler = nur Bergen (0% oder 100% Segel). Reefing-System = Bergen UND stufenloses Reffen (0% bis 100%). In der Praxis: Fast alle modernen Vorsegel-Rollsysteme sind Reefing-faehig (also beides). Der Begriff "Furler" wird umgangssprachlich fuer beides verwendet. Reine Furler (ohne Reff-Faehigkeit) findet man nur noch bei Code-0 und Gennaker (Top-Down-Furler), wo Reffen nicht vorgesehen ist.

**Confidence:** measured

### F16: Welche Foil-Laenge brauche ich genau?

**Antwort:** Exakte Berechnung: Messen Sie die Vorstag-Laenge (Masttopp-Befestigung bis Bugbeschlag-Auge). Ziehen Sie ab: Trommelhoehe (laut Hersteller-Datenblatt, typisch 100–250mm) + Top-Swivel-Hoehe (typisch 80–200mm) + 30–50mm Toleranz. Die resultierende Foil-Laenge wird durch Kombination von Standard-Sektionen (2.0m oder 2.5m) plus einer kuerzbaren Sektion erreicht.

**Confidence:** documented

### F17: Wie wichtig ist die Halyard-Spannung?

**Antwort:** Sehr wichtig, dreifacher Einfluss: (a) Zu wenig Spannung: Segel rutscht am Foil herunter, Falten am Kopf, Swivel kann herunterfallen. (b) Zu viel Spannung: Swivel-Lager wird ueberlastet (Verschleiss!), Segel rollt schwergaengig ein, erhoehter Trommel-Rollwiderstand. (c) Korrekte Spannung: Segel sitzt straff am Foil, Swivel dreht frei, Lager werden normal belastet. Faustformel: Fall spannen, bis Vorliek glatt ist und Swivel noch frei dreht.

**Confidence:** documented

### F18: Kann ich von einem Luff-Wire-System auf Profilfoile umsteigen?

**Antwort:** Ja, aber es erfordert: (a) Neuen Furler (Trommel + Foilsektionen + Swivel). (b) Neues Vorstag mit passendem Durchmesser fuer die Foile. (c) Neues Segel mit Luff Tape statt Luff Wire. Die Kosten fuer einen Komplettwechsel (Furler + Vorstag + Segel) liegen typisch bei €3.000–€6.000 fuer eine 33–38ft Yacht. Die Investition lohnt sich fuer die deutlich bessere Segelform und einfachere Handhabung.

**Confidence:** estimated

### F19: Was passiert, wenn der elektrische Furler bei Starkwind ausfaellt?

**Antwort:** Jeder elektrische Furler MUSS einen manuellen Override (Notfall-Handbetrieb) haben. Dies ist Pflicht und wird von allen seriösen Herstellern eingebaut. Typische Loesungen: (a) Manuelle Kurbel, die auf den Motor-Antrieb gesteckt wird. (b) Entkopplungshebel, der den Motor vom Getriebe trennt — danach kann normal mit Furler-Leine gerollt werden. (c) Separate Not-Furler-Leine. AYDI-Empfehlung: Manuellen Override VOR dem ersten Starkwind testen!

**Confidence:** documented

### F20: Wie viele Jahre haelt ein Furler?

**Antwort:** Lebensdauer der Hauptkomponenten: (a) Foilsektionen (Aluminium): 15–25 Jahre (bei regelmaessiger Suesswasser-Spuelung). (b) Trommelgehaeuse: 15–25 Jahre. (c) Lager: 5–10 Jahre (Verschleissteil, regelmaessig ersetzen). (d) Top-Swivel: 10–15 Jahre. (e) Furler-Leine: 3–5 Jahre (Verschleissteil). (f) UV-Streifen am Segel: 5–8 Jahre (Mittelmeer), 8–12 Jahre (Nordeuropa). Gesamtlebensdauer eines hochwertigen Furlers: 15–20+ Jahre bei guter Wartung.

**Confidence:** estimated

### F21: Welche Furler-Leine ist die beste?

**Antwort:** Fuer Cruising: Polyester-Flechtleine (16-fach geflochten, weich), Durchmesser 7–10mm. Marken: Liros Easycruise, Marlow, Robline. Fuer Performance: Dyneema-Kern mit Polyester-Mantel (duenner, weniger Dehnung). WICHTIG: Die Leine muss flexibel sein, damit sie sich sauber auf die Trommel wickelt. Keine steifen Leinen oder Leinen mit festem Kern verwenden!

**Confidence:** documented

### F22: Mein Furler laesst sich im Hafen nicht rollen — Wind ist zu schwach. Was tun?

**Antwort:** Ohne Wind muss die Schot die Entroll-Kraft aufbringen. Loesungen: (a) Lee-Schot kraeftig dichtholen und gleichzeitig Furler-Leine fieren. (b) Motor anstarten und langsam gegen den Wind fahren — kuenstlicher "Wind" hilft. (c) Person aufs Vorschiff, Segel manuell "ziehen". (d) Bei elektrischem Furler: Motor in "Ausrollen"-Richtung betaetigen. Grundsaetzlich: Rollreffsysteme sind primaer fuer den Einsatz unter Segeln konzipiert.

**Confidence:** estimated

### F23: Code 0 vs. Gennaker — wann brauche ich welchen Furler?

**Antwort:** Code 0 (flach, laminiert, 60–120° AWA): Wird mit Bottom-Up-Furler gerollt (Trommel am Bug). Kann teilweise gerefft werden (nicht ideal, aber funktional). Gennaker (bauchig, Nylon, 90–180° AWA): Wird mit Top-Down-Furler von oben gerollt ODER mit Snuffer/Sock geborgen. Reffen nicht vorgesehen. Empfehlung: Wenn beides geplant ist — Code-0-Furler (z.B. Karver KF) fuer das Code 0 und einen Snuffer fuer den Gennaker. Oder: Kombinations-System (z.B. Facnor FX+ fuer beides nutzbar).

**Confidence:** estimated

### F24: Wie viel Gewicht spart ein Carbon-Foil gegenueber Aluminium?

**Antwort:** Carbon-Foilsektionen sparen typisch 30–40% Gewicht gegenueber Aluminium bei gleicher Steifigkeit. Beispiel: 40ft Yacht, Foil-Laenge 15m: Aluminium-Foil ca. 6 kg, Carbon-Foil ca. 3.5–4 kg. Einsparung: ca. 2–2.5 kg. Kosten: Carbon-Foil ist 3–5× teurer als Aluminium. Sinnvoll nur fuer Racing oder Performance-orientierte Eigner, wo jedes Kilogramm am Vorstag die Stampfbewegung beeinflusst.

**Confidence:** estimated

### F25: Kann ich den Furler selbst installieren?

**Antwort:** Grundsaetzlich ja, fuer handwerklich erfahrene Eigner. Die Montage einer Rollreffanlage ist kein Raketenwissenschaft, erfordert aber: (a) Praezise Messungen. (b) Verstaendnis der Rigg-Kraaefte. (c) Werkzeug fuer Vorstag-Terminal-Verpressung (Swagelok) — ODER: Neues Vorstag mit fertig verpressten Terminals bestellen. (d) Mastresteigung oder Einsatz einer Arbeitsleine mit Bosun-Chair. (e) Sorgfaeltiges Arbeiten nach Hersteller-Anleitung. AYDI-Empfehlung: Bei Erstinstallation durch einen Rigg-Fachbetrieb vornehmen lassen (Kosten: €400–€800). Bei einfachem 1:1-Tausch eines bestehenden Systems: Eigenregie moeglich.

**Confidence:** estimated

## 11. Schnell-Referenz

### 11.1 Furler-Auswahl in 5 Schritten

```
Schritt 1: Vorstag messen
  → Laenge (Masttopp → Bugbeschlag) in mm
  → Durchmesser in mm (Draht mit Schieblehre messen)

Schritt 2: Segelflaeche bestimmen
  → Genua-Flaeche in m² (Segelvermessung oder Segelmacher)

Schritt 3: Furler-Groesse waehlen
  → Tabelle 4.4 verwenden: Segelflaeche → Furler-Klasse
  → Vorstag-Durchmesser pruefen: Passt der Foil?

Schritt 4: Hersteller waehlen
  → Tabelle 5.7 fuer Vergleich
  → OEM-Kompatibilitaet pruefen (gleicher Hersteller wie Mast)

Schritt 5: Zubehoer planen
  → Furler-Leine (Laenge + Durchmesser)
  → Umlenkbloecke (2–3 Stueck)
  → Beleger/Klemme im Cockpit
  → Ggf. Halyard-Lock
```

### 11.2 Wartungs-Checkliste (Jaehrlich)

```
□ Trommel mit Suesswasser spuelen (5 min)
□ Top-Swivel mit Suesswasser spuelen (Gartenschlauch von Deck)
□ Furler-Leine auf Verschleiss pruefen (Scheuerung, Haerchen, Verfaerbung)
□ Furler-Leine auf korrekte Wicklung pruefen (kein Override)
□ Foil-Verbindungen auf Festsitz pruefen (kein Spiel, kein Klappern)
□ UV-Schutzstreifen auf Nahtloesung und Risse pruefen
□ Trommel-Drehung testen (leichtgaengig, ohne Geraeusche)
□ Swivel-Drehung testen (leichtgaengig, ohne Knirschen)
□ Halyard-Fuehrung pruefen (kein Scheuerwerk am Foil)
□ Alle Bolzen und Sicherungen pruefen (Splinte, Sicherungsringe)
```

### 11.3 Notfall-Karte

```
NOTFALL: Segel rollt unkontrolliert aus (Leine gebrochen/gerutscht)
  1. NICHT in Panik geraten
  2. Sofort aufluven (Bug in den Wind) — Wind aus dem Segel nehmen
  3. Schoten dicht — Segel am Flattern hindern
  4. Motor starten (falls noetig zum Manoevrieren)
  5. Ersatzleine auf Trommel legen (oder Segel manuell auf Vorschiff bergen)
  6. Sicherheitsgurt tragen bei Arbeit am Vorschiff!

NOTFALL: Halyard-Wrap (Fall um Vorstag gewickelt)
  1. Nicht weiter rollen — macht es schlimmer!
  2. Segel ausrollen (sofern moeglich)
  3. Fall versuchen in Gegenrichtung zu "entwirren"
  4. Bei Blockade: Mast besteigen (Bosun-Chair, 2. Person sichert)
  5. Fall oben loesen, Wrap manuell aufloesen
  6. Langfristig: Halyard-Lock + Deflector installieren
```

## ANHANG C — Fallstudie 1: Nachruestung Furlex 200S auf Bavaria 37 Cruiser

### C.1 Ausgangssituation
- Boot: Bavaria 37 Cruiser (2008), LOA 11.35m, Deplacement 7.2 t
- Bestehendes System: Alter Profurl C350 (15 Jahre alt, Lager verschlissen, Foilverbinder gebrochen)
- Vorstag: 1×19, 8mm, Laenge 14.20m
- Genua: 38 m², Dacron, mit UV-Streifen

## ANHANG N — Installations-Checkliste

### N.1 Vor der Installation

```
□ Vorstag-Laenge exakt gemessen (±5mm)
□ Vorstag-Durchmesser exakt gemessen (Schieblehre, ±0.1mm)
□ Segelflaeche bekannt und dokumentiert
□ Furler-Modell ausgewaehlt und kompatibel geprueft (Tabelle ANHANG K)
□ Alle Komponenten vorhanden und vollstaendig (Checkliste Hersteller)
□ Werkzeug bereitgelegt (Innensechskant-Set, Schraubenschluessel, Saege, Feile)
□ Wetter: Windstill bis leichter Wind (max. 10 kn fuer Mastarbeit)
□ Helfer verfuegbar (min. 2 Personen fuer Masttop-Arbeiten)
□ Bosun-Chair oder Mastleiter fuer Masttop-Zugang
```

### N.2 Waehrend der Installation

```
□ Altes System (falls vorhanden) demontiert und dokumentiert
□ Neues Vorstag mit Terminals montiert (Pressung oder Norseman)
□ Trommel auf Vorstag aufgefaedelt — ACHTUNG: Reihenfolge beachten!
□ Foilsektionen in korrekter Reihenfolge aufgefaedelt
□ Foilverbinder fest und geprueft (kein Spiel, kein Klappern)
□ Letzte Foilsektion auf Restmass gekuerzt und entgratet
□ Top-Swivel montiert — Leichtgaengigkeit geprueft
□ Vorstag mit neuem Furler-System in Mast eingehaengt
□ Vorstag-Spannung gesetzt (Achterstag justieren)
□ Trommel-Ausrichtung geprueft (<2° Achsabweichung)
□ Segel eingefaedelt (Luff Tape in Foilnut)
□ Halyard angeschlagen und gesetzt
□ Furler-Leine eingefaedelt und ueber Umlenkbloecke ins Cockpit gefuehrt
□ Funktionstest: 3× komplett ein- und ausrollen
□ Wickelbild pruefen: Gleichmaessig, keine Beulen
□ Alle Bolzen gesichert (Splinte, Sicherungsringe, Loctite)
```

### N.3 Nach der Installation

```
□ Dokumentation: Modell, Seriennummer, Einbaudatum notiert
□ Hersteller-Registrierung fuer Garantie durchgefuehrt
□ Ersatzteil-Liste erstellt (Lager-Kit, Verbinder, Furler-Leine)
□ Wartungsplan erstellt (naechste Wartung: +12 Monate)
□ Crew-Briefing: Bedienung Ein-/Ausrollen, Notfall-Prozedur
□ Fotos der Installation fuer AYDI-Dokumentation
```

from pydantic import BaseModel, Field
from typing import Optional, Literal
from enum import Enum


class FurlerType(str, Enum):
    """Types of headsail furling systems."""
    MANUAL_DRUM = "manual_drum"
    CONTINUOUS_LINE = "continuous_line"
    TOP_DOWN = "top_down"
    UNDER_DECK = "under_deck"
    ELECTRIC = "electric"
    CODE_ZERO = "code_zero"
    ASYMMETRIC_SPINNAKER = "asymmetric_spinnaker"
    CAPTIVE_REEL = "captive_reel"


class FoilType(str, Enum):
    """Types of foil extrusion profiles."""
    ROUND = "round"
    TEARDROP = "teardrop"
    TWIN_GROOVE = "twin_groove"
    NONE = "none"  # For code 0 / gennaker without foil


class LuffAttachment(str, Enum):
    """How the sail is attached to the luff."""
    LUFF_WIRE = "luff_wire"
    LUFF_TAPE = "luff_tape"
    INTEGRAL_FOIL = "integral_foil"


class DrumType(str, Enum):
    """Types of furling drums."""
    OPEN = "open"
    ENCLOSED = "enclosed"
    CONTINUOUS_LINE = "continuous_line"
    UNDER_DECK = "under_deck"
    CAPTIVE_REEL = "captive_reel"


class FurlerManufacturer(str, Enum):
    """Known furler manufacturers."""
    SELDEN = "selden"
    FACNOR = "facnor"
    PROFURL = "profurl"
    HARKEN = "harken"
    RECKMANN = "reckmann"
    KARVER = "karver"
    OTHER = "other"


class FurlerSpec(BaseModel):
    """Specification for a headsail furling system.

    Contains all measured and documented parameters for AYDI analysis.
    """
    model_config = {"from_attributes": True}

    # Identification
    manufacturer: FurlerManufacturer
    model_name: str = Field(..., description="Model designation, e.g. 'Furlex 200S'")
    part_number: Optional[str] = Field(None, description="Manufacturer part number")
    furler_type: FurlerType
    drum_type: DrumType
    foil_type: FoilType
    luff_attachment: LuffAttachment

    # Dimensions
    forestay_diameter_min_mm: float = Field(..., ge=3.0, le=30.0)
    forestay_diameter_max_mm: float = Field(..., ge=3.0, le=30.0)
    foil_outer_diameter_mm: Optional[float] = Field(None, ge=10.0, le=100.0)
    max_forestay_length_m: float = Field(..., ge=5.0, le=60.0)
    max_sail_area_m2: float = Field(..., ge=5.0, le=800.0)

    # Weight
    drum_weight_kg: float = Field(..., ge=0.3, le=50.0)
    total_system_weight_kg: Optional[float] = Field(
        None, ge=0.5, le=100.0,
        description="Total weight including foils, drum, swivel"
    )

    # Electrical (for electric furlers)
    voltage_v: Optional[int] = Field(None, description="Operating voltage: 12, 24, or 48")
    max_current_a: Optional[float] = Field(None, description="Maximum current draw in amps")
    motor_power_w: Optional[int] = Field(None, description="Motor power in watts")

    # Pricing
    price_eur_min: Optional[float] = Field(None, ge=0)
    price_eur_max: Optional[float] = Field(None, ge=0)

    # Performance
    continuous_line: bool = Field(False, description="Continuous line option available")
    twin_groove: bool = Field(False, description="Twin groove foil option available")
    manual_override: bool = Field(True, description="Manual override capability")


class FurlerConditionAssessment(BaseModel):
    """Condition assessment of an installed furling system.

    Used by AYDI visual and structural analysis modules.
    """
    model_config = {"from_attributes": True}

from pydantic import BaseModel, Field, computed_field
from typing import Optional
import math


class FurlerSizingInput(BaseModel):
    """Input parameters for furler sizing calculation."""
    model_config = {"from_attributes": True}

    forestay_length_m: float = Field(..., ge=5.0, le=60.0,
        description="Forestay length from masthead to bow fitting")
    forestay_diameter_mm: float = Field(..., ge=3.0, le=30.0,
        description="Forestay wire diameter")
    sail_area_m2: float = Field(..., ge=5.0, le=800.0,
        description="Maximum headsail area")
    boat_loa_m: float = Field(..., ge=5.0, le=100.0)
    boat_displacement_t: float = Field(..., ge=0.5, le=200.0)
    max_wind_speed_kn: float = Field(default=30.0, ge=5.0, le=60.0,
        description="Maximum design wind speed")
    electric_preferred: bool = Field(default=False)
    code_zero: bool = Field(default=False,
        description="True if sizing for code 0 furler")

    @computed_field
    @property
    def estimated_torque_nm(self) -> float:
        """Estimate required furling torque at max wind, 50% furled."""
        wind_speed_ms = self.max_wind_speed_kn * 0.5144
        wind_pressure = 0.5 * 1.225 * wind_speed_ms ** 2 * 1.2
        # Approximate lever arm at 50% furled
        foil_diameter_m = (self.forestay_diameter_mm + 10) / 1000
        n_turns = self.forestay_length_m / (math.pi * foil_diameter_m)
        cloth_thickness = 0.0004  # 0.4mm per layer
        n_layers_half = n_turns / 2
        roll_diameter = foil_diameter_m + 2 * n_layers_half * cloth_thickness
        lever_arm = roll_diameter / 2
        torque = self.sail_area_m2 * wind_pressure * lever_arm * 0.15
        return round(torque, 1)

    @computed_field
    @property
    def recommended_furler_class(self) -> str:
        """Recommend furler size class based on sail area."""
        area = self.sail_area_m2
        if area <= 15:
            return "XS"
        elif area <= 25:
            return "S"
        elif area <= 38:
            return "M"
        elif area <= 55:
            return "L"
        elif area <= 75:
            return "XL"
        elif area <= 100:
            return "XXL"
        elif area <= 150:
            return "3XL"
        else:
            return "4XL+"


class FurlerSizingResult(BaseModel):

### R.3 Elektrische Furler — Detaillierte Spezifikationen

**Kabelquerschnitt-Berechnung fuer E-Furler:**

```
Erforderlicher Kabelquerschnitt (mm²):
  A = (2 × L × I) / (κ × U_drop)

  L = Kabellaenge (einfache Strecke, Batterie → Motor) in Metern
  I = Strom in Ampere
  κ = Leitfaehigkeit Kupfer = 56 m/(Ω×mm²)
  U_drop = max. zulaessiger Spannungsabfall (typisch 3% der Nennspannung)
    12V-System: U_drop = 0.36V
    24V-System: U_drop = 0.72V
```

**Beispielrechnung:**

| Parameter | 12V-System | 24V-System |
|-----------|-----------|-----------|
| Motor: Facnor FXe 250, 600W | | |
| Strom (max): | 55A | 28A |
| Kabellaenge (einfach): | 8m | 8m |
| Spannungsabfall (max 3%): | 0.36V | 0.72V |
| Berechnung A: | (2×8×55)/(56×0.36) = 43.7 mm² | (2×8×28)/(56×0.72) = 11.1 mm² |
| Naechster Standard-Querschnitt: | 50 mm² (AWG 1/0) | 16 mm² (AWG 6) |

> ⚠️ **ZU PRÜFEN (Audit):** Die Beispielrechnung oben ergibt fuer 55 A / 8 m / 12 V / 3 % Spannungsabfall 43,7 mm² (→ Standardquerschnitt 50 mm²). Die Nachschlagetabellen unten nennen fuer identische Eingangswerte (55 A / 8 m / 12 V / 3 %) jedoch 61 mm². Alle Tabellenwerte liegen durchgehend rund 40 % ueber dem Formelergebnis — vermutlich eine nicht ausgewiesene Derating-/Sicherheitsreserve, moeglicherweise aber ein Fehler. ### R.11 Detaillierte Wartungsprozeduren

**Prozedur W1: Jaehrliche Trommel-Wartung (30–60 min)**

```
Werkzeug: Innensechskant-Set, Schraubenschluessel (passend zur Trommel),
          Suesswasser, Marine-Fett (Harken Winch Grease oder aequivalent),
          Lappen, Spruehdose WD-40 oder Teflon-Spray

Schritt 1: Segel vollstaendig ausrollen
Schritt 2: Furler-Leine von Trommel abwickeln
Schritt 3: Trommelgehaeuse oeffnen (Schrauben/Clips je nach Hersteller)
Schritt 4: Altes Fett entfernen (Lappen, ggf. WD-40)
Schritt 5: Lager inspizieren:
  - Leichtgaengig? → OK, weiter
  - Knirschen/Spiel? → Lager-Kit bestellen und tauschen
  - Korrosion sichtbar? → Lager SOFORT tauschen
Schritt 6: Neues Marine-Fett auf Lager auftragen (duenne Schicht, nicht ueberfetten!)
Schritt 7: Trommelgehaeuse schliessen, Schrauben mit korrektem Drehmoment anziehen
Schritt 8: Furler-Leine wieder einfaedeln
Schritt 9: Funktionstest: 2× komplett ein- und ausrollen
Schritt 10: Dokumentieren (Datum, Zustand, naechster Termin)
```

**Prozedur W2: Top-Swivel-Wartung (15–30 min, erfordert Mastbesteigung)**

```
Werkzeug: Bosun-Chair, Sicherheitsgurt, Innensechskant,
          Suesswasser-Spruehflasche, Teflon-Spray, Lappen

Schritt 1: Mast besteigen mit Bosun-Chair (2. Person sichert!)
Schritt 2: Swivel visuell inspizieren:
  - Korrosion? Verfaerbung? Risse?
  - Halyard-Befestigung fest?
  - Foil-Verbindung zum Swivel fest?
Schritt 3: Swivel mit Suesswasser spuelen (Spruehflasche)
Schritt 4: Teflon-Spray in Lager-Bereich spruehen
Schritt 5: Swivel von Hand drehen — muss leichtgaengig und gleichmaessig sein
Schritt 6: Falls Knirschen/Widerstand → Lager-Kit bestellen (Austausch bei naechster Gelegenheit)
Schritt 7: Halyard-Fuehrung pruefen (kein Scheuerwerk am Foil?)
Schritt 8: Absteigen, dokumentieren
```

**Prozedur W3: Foil-Inspektion (45–90 min)**

```
Schritt 1: Segel vollstaendig ausrollen
Schritt 2: Gesamte Foillaenge von Deck aus visuell inspizieren (Fernglas fuer obere Sektionen)
Schritt 3: Zugaengliche Foilverbindungen auf Spiel pruefen (leicht wackeln → OK, deutliches Klappern → nachziehen)
Schritt 4: Auf Korrosion achten:
  - Weisse Pulverflecken auf Aluminium = Oberflaechenkorrosion (normal, harmlos)
  - Tiefe Lochfraesse = ERSETZEN
  - Braune Verfaerbung = Galvanische Korrosion (Ursache finden!)
Schritt 5: Foil-Geradlinigkeit pruefen (Auge entlang der Foillaenge peilen)
  - Sichtbare Verbiegung > 5mm/m → Foilsektion ersetzen
Schritt 6: Foilnut pruefen:
  - Sauber und frei? → OK
  - Korrosion in der Nut? → Mit feinem Schleifpapier (400er) reinigen
  - Beschaedigung der Nutlippen? → Foilsektion ersetzen
Schritt 7: Dokumentieren, auffaellige Sektionen markieren
```

**Prozedur W4: Furler-Leinen-Austausch (15–30 min)**

```
Schritt 1: Alte Leine von Trommel und Cockpit-Fuehrung loesen
Schritt 2: Leinenlaenge messen (alte Leine als Referenz)
Schritt 3: Neue Leine am Ende mit Klebeband umwickeln (Einfaedelhilfe)
Schritt 4: Neue Leine in Trommel einlegen:
  - Leinenende in Trommel einfuehren (Befestigungsart je nach Hersteller)
  - 3–4 saubere Grundwicklungen auf Trommel legen
  - Darauf achten, dass Leine sich NICHT ueberkreuzt (Override-Gefahr!)
Schritt 5: Leine ueber Umlenkbloecke ins Cockpit fuehren
Schritt 6: Funktionstest: 3× komplett ein- und ausrollen
Schritt 7: Leinenlaenge pruefen: Bei voll eingerolltem Segel muss min. 2m Restleine am Cockpit-Beleger sein
```

### S.1 Anhang — Typische Fragen bei der Yacht-Besichtigung (AYDI Survey-Modul)

Bei einer Yacht-Besichtigung (Survey) sollten folgende Fragen zur Rollreffanlage gestellt und dokumentiert werden:

**Allgemeine Fragen:**

| Nr. | Frage | Erwartete Antwort | AYDI-Relevanz |
|-----|-------|------------------|--------------|
| 1 | Welcher Furler-Hersteller und welches Modell? | Hersteller + Modell | Datenbank-Abgleich |
| 2 | Wann wurde der Furler installiert (Jahrgang)? | Jahr | Altersberechnung, Restlebensdauer |
| 3 | Wurde der Furler jemals getauscht? | Ja/Nein + Jahr | Zustandsbewertung |
| 4 | Wann wurden die Lager zuletzt getauscht? | Jahr oder "nie" | Wartungszustand-Score |
| 5 | Wird die Trommel regelmaessig mit Suesswasser gespuelt? | Ja/Nein + Haeufigkeit | Korrosions-Risiko |
| 6 | Gab es jemals einen Halyard-Wrap? | Ja/Nein | Risiko-Bewertung |
| 7 | Ist ein Halyard-Lock installiert? | Ja/Nein | Ergonomie- und Sicherheits-Score |
| 8 | Wird das Segel im Winter abgeschlagen? | Ja/Nein | UV/Feuchtigkeits-Risiko |
| 9 | Wann wurde der UV-Streifen zuletzt erneuert? | Jahr oder "Original" | Material-Score |
| 10 | Gibt es Probleme beim Ein- oder Ausrollen? | Beschreibung | Fehlerbild-Zuordnung |

**Technische Pruefung (Surveyor):**

| Nr. | Pruefpunkt | Methode | Akzeptabel | Grenzwertig | Unakzeptabel |
|-----|-----------|---------|-----------|-------------|-------------|
| 1 | Trommel-Leichtgaengigkeit | Hand-Drehtest | Leichtgaengig, gleichmaessig | Leichter Widerstand, kein Knirschen | Schwergaengig, knirscht, blockiert |
| 2 | Swivel-Leichtgaengigkeit | Mastbesteigung, Hand-Test | Leichtgaengig | Leichter Widerstand | Blockiert oder knirscht |
| 3 | Foilverbindungen | Wackeltest an zugaenglichen Stellen | Kein Spiel | Leichtes Spiel (<1mm) | Deutliches Spiel (>1mm) oder Luecke |
| 4 | Foil-Oberflaeche | Visuell | Glatt, gleichmaessig eloxiert | Oberflaechenkorrosion (weiss) | Tiefe Korrosion, Lochfrass |
| 5 | Trommelgehaeuse | Visuell + Taktil | Unbeschaedigt, dicht | Leichte Verfaerbung | Risse, Korrosionsloecher |
| 6 | Furler-Leine | Visuell + Taktil | Glatt, geschmeidig | Leichte Haarigkeit | Haarig, steif, verfaerbt |
| 7 | UV-Streifen | Visuell | Geschlossen, keine Risse | Leichte Nahtloesung | Gerissen, durchscheinend |
| 8 | Vorstag (sichtbarer Teil) | Visuell | Glatt, keine gebrochenen Draehte | 1–2 gebrochene Draehte | 3+ gebrochene Draehte → ERSETZEN |
| 9 | Toggle-Verbindung | Visuell + Wackeltest | Fest, kein Spiel | Leichtes Spiel | Deutliches Spiel → nachziehen |
| 10 | Halyard-Fuehrung | Visuell | Kein Scheuerwerk am Foil | Leichte Scheuermarken | Deutliche Scheuerrillen |
